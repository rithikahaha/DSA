# 572. Subtree of Another Tree
LeetCode: https://leetcode.com/problems/subtree-of-another-tree/ · Easy · Pattern: Tree recursion (reuses Same Tree)

## Problem
Given the roots of two binary trees `root` and `subRoot`, return `true` if some subtree of `root` (a node plus all of its descendants) has exactly the same structure and values as `subRoot`.

**Example**
```
Input: root = [1,2,3,4,5], subRoot = [2,4,5]
Output: true
```

## Solution
```python
class Solution:
    def isSubtree(self, root, subRoot):
        if not root:
            return False
        if self.isSameTree(root, subRoot):
            return True
        return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)

    def isSameTree(self, p, q):
        if not p and not q:
            return True
        if not p or not q or p.val != q.val:
            return False
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

Using `root = [1,2,3,4,5]`, `subRoot = [2,4,5]`:

1. Two questions are combined: "is the tree starting *here* identical to `subRoot`?" (that's problem 100, `isSameTree`) and "if not, does it match somewhere further down?".
2. `isSubtree(root, ...)`: if `root` is empty, nothing is left to match → `False`.
3. At node `1`: `isSameTree(1-tree, subRoot)` → values differ → no match. Try the children: `isSubtree(root.left)` **or** `isSubtree(root.right)`.
4. At node `2`: `isSameTree` compares `2` with `2`, then `4` with `4`, then `5` with `5`. Everything matches → `True`.
5. Because of the `or`, one match anywhere is enough.

Each node of `root` may trigger a comparison of up to `m` nodes (the size of `subRoot`), so it's O(n·m) time and O(h) space.
