# 572. Subtree of Another Tree
LeetCode: https://leetcode.com/problems/subtree-of-another-tree/ · Easy · Pattern: Tree recursion (reuses Same Tree)

## Problem
Given two binary trees `root` and `subRoot`, return `True` if `subRoot` appears **somewhere inside** `root` as a complete subtree (a node plus *all* of its descendants, identical in shape and values).

```
root:      1        subRoot:   2
          / \                 / \
         2   3               4   5
        / \
       4   5                          Output: True  (the subtree starting at node 2)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **subtree** | Pick any node; that node plus everything below it is a subtree. |
| **`isSameTree`** | A helper (problem 100) that answers "are these two trees identical?". |
| **recursion** | A function that calls itself on smaller pieces. |
| **`or`** | True if **at least one** side is true. |

## How to come up with it (the thinking)
**Step 1: split it into two easy questions.**
1. Is the tree starting at **this** node exactly the same as `subRoot`? (We already know how to check that: `isSameTree`.)
2. If not, could `subRoot` be hiding somewhere **further down**, in the left or right side?

**Step 2: combine them.** Try the current node. If it doesn't match, ask the same question about the left child, **or** the right child. One success anywhere is enough.

**Step 3: base case.** If we've run out of tree (`root` is `None`) and haven't found a match, the answer is `False`.

## Solution
```python
class Solution:
    def isSubtree(self, root, subRoot):
        if not root:
            return False
        if self.isSameTree(root, subRoot):
            return True
        return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)

    def isSameTree(self, p, q):
        if not p and not q:
            return True
        if not p or not q or p.val != q.val:
            return False
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

## Line by line
**`isSubtree`**

| Line | What it does |
|---|---|
| `if not root: return False` | We ran out of tree without finding a match. |
| `if self.isSameTree(root, subRoot): return True` | Does the tree starting right here equal `subRoot`? Then we found it. |
| `return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)` | Otherwise look in the left side or the right side. |

**`isSameTree`** (same as problem 100)

| Line | What it does |
|---|---|
| `if not p and not q: return True` | Both empty → match. |
| `if not p or not q or p.val != q.val: return False` | Only one is empty, or the values differ → no match. |
| `return ... and ...` | Left subtrees match **and** right subtrees match. |

## Watch it run
`root = 1 (2 (4, 5), 3)`, `subRoot = 2 (4, 5)`

| Call | Question | Answer |
|---|---|---|
| `isSubtree(1)` | Is the tree at 1 the same as `subRoot`? (`isSameTree(1, 2)`: values 1 ≠ 2) | No |
| → try left: `isSubtree(2)` | Is the tree at 2 the same as `subRoot`? | |
| → `isSameTree(2, 2)` | values equal → check children | |
| → left `isSameTree(4, 4)` | equal, both leaves | True |
| → right `isSameTree(5, 5)` | equal, both leaves | True |
| result | | **True** |

Answer: **True** ✅ (The right branch, node 3, never even needs to be checked.)

## How fast is it?
- **Time: O(n · m).** For each of the n nodes of `root` we might compare up to m nodes of `subRoot`.
- **Space: O(h).** Recursion depth.
