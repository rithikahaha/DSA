# 100. Same Tree
LeetCode: https://leetcode.com/problems/same-tree/ · Easy · Pattern: Tree recursion (DFS)

## Problem
Given the roots of two binary trees `p` and `q`, return `true` if they are structurally identical and every corresponding node has the same value.

**Example 1**
```
Input: p = [1,2,3], q = [1,2,3]
Output: true
```

**Example 2**
```
Input: p = [4,7], q = [4,null,7]
Output: false      (7 is a left child in one tree, a right child in the other)
```

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        if not p and not q:
            return True
        if not p or not q:
            return False
        if p.val != q.val:
            return False

        return (self.isSameTree(p.left, q.left) and
                self.isSameTree(p.right, q.right))
```

Using `p = [4,7]` and `q = [4,null,7]`:

1. Compare the two trees one pair of nodes at a time.
2. **Both empty** → they match here → `True`.
3. **Only one empty** → shapes differ → `False`.
4. **Values differ** → `False`.
5. Otherwise the roots match, so the trees are the same only if the **left subtrees are the same and the right subtrees are the same**.
6. Roots `4` and `4` match. Left pair: `7` vs `None` → exactly one is empty → `False`. The `and` fails, so the answer is `False`.

The order of the checks matters: handle "both empty" first, so the later lines can safely read `p.val`. O(n) time, O(h) space.
