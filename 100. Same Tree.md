# 100. Same Tree
LeetCode: https://leetcode.com/problems/same-tree/ · Easy · Pattern: Tree recursion (DFS)

## Problem
Given the roots of two binary trees `p` and `q`, return `True` if they are **identical**: same shape and same values in every spot.

```
p:   1        q:   1
    / \           / \
   2   3         2   3          → True

p:   4        q:   4
    /              \
   7                7            → False  (7 is on the left in one tree, on the right in the other)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary tree** | Each **node** has a value and at most two children, `left` and `right`. |
| **`None`** | An empty spot where a child could be. |
| **recursion** | A function that calls itself on smaller pieces. |
| **base case** | The obvious smallest situation where we can answer without calling again. |

## How to come up with it (the thinking)
**Step 1: compare one pair of spots.** Look at the two nodes in the *same position* in each tree. Three things can happen:
- **Both empty** → they match here. ✅
- **Only one is empty** → the shapes are different. ❌
- **Both exist but have different values** → different. ❌

**Step 2: if they match here, what's left?** Their **left** subtrees must match **and** their **right** subtrees must match. That's the same question on smaller trees, so call the function again.

**Step 3: order matters.** Handle "both empty" **first**. Only then is it safe to ask for `p.val`, because we know neither is empty by then.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        if not p and not q:
            return True
        if not p or not q:
            return False
        if p.val != q.val:
            return False

        return (self.isSameTree(p.left, q.left) and
                self.isSameTree(p.right, q.right))
```

## Line by line
| Line | What it does |
|---|---|
| `if not p and not q: return True` | Both empty → same. |
| `if not p or not q: return False` | (We know they aren't both empty.) If one is empty, the other isn't → different shape. |
| `if p.val != q.val: return False` | Both exist, but values differ → different. |
| `self.isSameTree(p.left, q.left)` | Are the left subtrees the same? |
| `and self.isSameTree(p.right, q.right)` | ...**and** are the right subtrees the same? Both must be true. |

## Watch it run
`p = 4 with left child 7`, `q = 4 with right child 7`

| Call | `p` | `q` | Check | Result |
|---|---|---|---|---|
| `isSameTree(4, 4)` | 4 | 4 | values equal → look at children | needs left **and** right |
| → left: `isSameTree(7, None)` | 7 | `None` | only one is empty | **False** |

Because the left comparison is `False`, the `and` is `False` (the right side isn't even checked). Answer: **False** ✅

## How fast is it?
- **Time: O(n).** At most every node is compared once.
- **Space: O(h).** Recursion depth equals the tree height.
