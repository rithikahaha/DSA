# 238. Product of Array Except Self
LeetCode: https://leetcode.com/problems/product-of-array-except-self/ · Medium · Pattern: Prefix / postfix products

## Problem
Given an integer array `nums`, return an array `output` where `output[i]` is the product of every element of `nums` except `nums[i]`. You must not use division, and it should run in O(n).

**Example**
```
Input: nums = [1,2,4,6]
Output: [48,24,12,8]
```

## Solution
```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        res = [1] * (len(nums))

        prefix = 1
        for i in range(len(nums)):
            res[i] = prefix
            prefix *= nums[i]
        postfix = 1
        for i in range(len(nums) - 1, -1, -1):
            res[i] *= postfix
            postfix *= nums[i]
        return res
```

Using `nums = [1,2,4,6]`:

1. For each index, the answer is (product of everything to its left) × (product of everything to its right).
2. **Left-to-right pass:** `res[i] = prefix` first, then `prefix *= nums[i]`. Storing before multiplying keeps `nums[i]` itself out of its own answer. Result: `res = [1, 1, 2, 8]`.
3. **Right-to-left pass:** `postfix` starts at 1. `res[i] *= postfix`, then `postfix *= nums[i]`.
   - i=3: `8 × 1 = 8`, postfix becomes 6
   - i=2: `2 × 6 = 12`, postfix becomes 24
   - i=1: `1 × 24 = 24`, postfix becomes 48
   - i=0: `1 × 48 = 48`
4. Final `res = [48, 24, 12, 8]`.

Dividing the total product by `nums[i]` fails when there's a zero in the array, which is why division is banned. Two passes over the array give O(n) time. The output array is the only storage, so extra space is O(1).
