# 19. Remove Nth Node From End of List
LeetCode: https://leetcode.com/problems/remove-nth-node-from-end-of-list/ · Medium · Pattern: Two pointers with a gap + dummy node

## Problem
Given the head of a linked list and a number `n`, **remove the `n`-th node counting from the end** and return the head.

```
Input:  1 → 2 → 3 → 4,  n = 2
Output: 1 → 2 → 4          (the 2nd from the end, node 3, is removed)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **linked list** | A chain of people holding hands; each **node** knows only who is next (`next`). |
| **dummy node** | A fake extra person placed in front of the head, so that removing the *first* real node needs no special case. |
| **removing a node** | Make the person **before** it hold hands with the person **after** it: `before.next = before.next.next`. |

## How to come up with it (the thinking)
**Step 1: the problem.** We know how to remove a node *if we're standing on the node before it*. But "n-th from the **end**" is hard: a linked list doesn't tell us its length, and we can only walk forward.

**Step 2: the obvious idea.** Walk the whole list once to count its length `L`, then walk again to position `L - n`. It works, but takes two passes.

**Step 3: the trick, keeping a gap.** Use two markers, `left` and `right`, that stay **exactly `n` nodes apart**. Move both forward together. The moment `right` falls off the end, `left` is exactly `n` from the end, right before the node to delete.

**Step 4: set it up.** Start `right` and move it forward `n` steps first to create the gap. Then move both until `right` is `None`.

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        left = dummy
        right = head

        while n > 0 and right:
            right = right.next
            n -= 1

        while right:
            left = left.next
            right = right.next

        left.next = left.next.next
        return dummy.next
```

## Line by line
| Line | What it does |
|---|---|
| `dummy = ListNode(0, head)` | A fake node whose `next` is the real head. |
| `left = dummy` | `left` starts on the dummy (one step behind the head). |
| `right = head` | `right` starts on the first real node. |
| `while n > 0 and right:` | Repeat `n` times... |
| `right = right.next; n -= 1` | ...moving `right` forward. This builds the gap of `n` nodes. |
| `while right:` | Now move both markers together until `right` falls off the end. |
| `left = left.next; right = right.next` | One step each. |
| `left.next = left.next.next` | `left` is right before the target. Skip over the target. |
| `return dummy.next` | The real head. (If we removed the old head, this is now the new head.) |

## Watch it run
`1 → 2 → 3 → 4`, `n = 2` → we want to remove `3`.
Chain with the dummy: `D → 1 → 2 → 3 → 4`

**Creating the gap** (`right` starts at 1, `left` at D):

| Move | `right` | `n` left |
|---|---|---|
| 1 | 2 | 1 |
| 2 | 3 | 0 |

**Moving together** until `right` is `None`:

| Move | `left` | `right` |
|---|---|---|
| 1 | 1 | 4 |
| 2 | 2 | `None` |

`left` is on node 2, and `left.next` is 3. Set `left.next = left.next.next` (node 4) → `1 → 2 → 4` ✅

## How fast is it?
- **Time: O(n).** One pass through the list.
- **Space: O(1).**
