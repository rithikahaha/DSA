# 19. Remove Nth Node From End of List
LeetCode: https://leetcode.com/problems/remove-nth-node-from-end-of-list/ · Medium · Pattern: Two pointers with a gap + dummy node

## Problem
Given the head of a linked list and an integer `n`, remove the `n`-th node from the **end** of the list and return the head.

**Example**
```
Input: head = [1,2,3,4], n = 2
Output: [1,2,4]
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        left = dummy
        right = head

        while n > 0 and right:
            right = right.next
            n -= 1

        while right:
            left = left.next
            right = right.next

        left.next = left.next.next
        return dummy.next
```

Using `1 → 2 → 3 → 4`, `n = 2` (remove `3`):

1. You can't count from the end of a singly linked list. Trick: keep two pointers exactly `n` nodes apart. When the front pointer falls off the end, the back pointer is right before the node to delete.
2. `dummy → 1 → 2 → 3 → 4`. `left = dummy`, `right = head (1)`.
3. Move `right` forward `n = 2` steps → `right = 3`. The gap is now 2.
4. Move both together until `right` is `None`: `right` goes 3 → 4 → `None`, and `left` goes dummy → 1 → 2.
5. `left` (node 2) sits just before the node to remove. `left.next = left.next.next` skips over `3` → `1 → 2 → 4`.
6. Return `dummy.next`. The dummy is what makes removing the **head** work too (`left` ends on the dummy itself).

One pass: O(n) time, O(1) space.
