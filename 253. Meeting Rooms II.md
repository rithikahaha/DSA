# 253. Meeting Rooms II
LeetCode: https://leetcode.com/problems/meeting-rooms-ii/ · Medium · Pattern: Sorted starts/ends + two pointers

## Problem
Given a list of meetings (start, end), find the **minimum number of rooms** needed so that every meeting has a room.

```
Input: [(0,40), (5,10), (15,20)]     Output: 2
   (the 0–40 meeting is going on the whole time; the other two never overlap each other, so they share one room)
Input: [(4,9)]                       Output: 1
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **interval** | A stretch of time with a start and an end. |
| **overlap** | Two meetings happening at the same time. |
| **`count`** | How many meetings are running **right now**. |
| **two pointers `s`, `e`** | `s` walks along the sorted **start** times; `e` walks along the sorted **end** times. |

## How to come up with it (the thinking)
**Step 1: what does the answer really equal?** The number of rooms needed is the **largest number of meetings happening at the same moment**. If at some moment 3 meetings run at once, we need 3 rooms.

**Step 2: think of a door counter.** Imagine counting people entering and leaving a room. A meeting **starting** is +1; a meeting **ending** is −1. The highest the counter ever reaches is the answer.

**Step 3: we don't care which start belongs to which end.** All that matters is the order of events in time. So sort all the **start times** on their own, and all the **end times** on their own.

**Step 4: process events in time order.** Compare the next start with the earliest end:
- The next **start** comes first (`start < end`) → a meeting begins → `count + 1`.
- Otherwise a meeting **ends** first → `count − 1`.

Keep the highest `count`.

## Solution
```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

class Solution:
    def minMeetingRooms(self, intervals: List[Interval]) -> int:
        start = sorted([i.start for i in intervals])
        end = sorted([i.end for i in intervals])

        res, count = 0, 0
        s, e = 0, 0
        while s < len(intervals):
            if start[s] < end[e]:
                s += 1
                count += 1
            else:
                e += 1
                count -= 1
            res = max(res, count)
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `start = sorted([i.start for i in intervals])` | A sorted list of all start times. |
| `end = sorted([i.end for i in intervals])` | A sorted list of all end times. |
| `res, count = 0, 0` | `res` = most rooms needed so far; `count` = meetings running now. |
| `s, e = 0, 0` | Position in the start list and in the end list. |
| `while s < len(intervals):` | Continue until every start has been processed. |
| `if start[s] < end[e]:` | Does the next meeting start before the earliest running meeting ends? |
| `s += 1; count += 1` | Yes → a meeting starts. One more running. |
| `else: e += 1; count -= 1` | No → a meeting ends first. One fewer running. |
| `res = max(res, count)` | Remember the busiest moment. |

## Watch it run
`[(0,40), (5,10), (15,20)]` → starts sorted: `[0, 5, 15]`, ends sorted: `[10, 20, 40]`

| Step | Next start `start[s]` | Earliest end `end[e]` | Which is earlier? | `count` | `res` |
|---|---|---|---|---|---|
| 1 | 0 | 10 | start (0 < 10) | 1 | 1 |
| 2 | 5 | 10 | start (5 < 10) | 2 | 2 |
| 3 | 15 | 10 | end (15 ≥ 10) | 1 | 2 |
| 4 | 15 | 20 | start (15 < 20) | 2 | 2 |

All three starts are processed (`s = 3`), so we stop. Answer: **2** ✅

## How fast is it?
- **Time: O(n log n).** Sorting the two lists.
- **Space: O(n).** The two sorted lists.
