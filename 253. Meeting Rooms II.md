# 253. Meeting Rooms II
LeetCode: https://leetcode.com/problems/meeting-rooms-ii/ · Medium · Pattern: Sorted starts/ends + two pointers

## Problem
Given an array of meeting time intervals `[start, end)`, return the minimum number of conference rooms needed so that all meetings can take place.

**Example 1**
```
Input: intervals = [(0,40),(5,10),(15,20)]
Output: 2
```

**Example 2**
```
Input: intervals = [(4,9)]
Output: 1
```

## Solution
```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

class Solution:
    def minMeetingRooms(self, intervals: List[Interval]) -> int:
        start = sorted([i.start for i in intervals])
        end = sorted([i.end for i in intervals])

        res, count = 0, 0
        s, e = 0, 0
        while s < len(intervals):
            if start[s] < end[e]:
                s += 1
                count += 1
            else:
                e += 1
                count -= 1
            res = max(res, count)
        return res
```

Using `[(0,40),(5,10),(15,20)]`:

1. Rooms needed = the largest number of meetings happening **at the same moment**. So walk through time and keep a running count of meetings in progress.
2. Sort the start times and the end times **separately**: `start = [0,5,15]`, `end = [10,20,40]`. Which meeting a time belongs to no longer matters; only "a meeting started" and "a meeting ended" do.
3. `s` points at the next start and `e` at the earliest end.
4. `0 < 10` → a meeting starts before any has ended: `count = 1`, `res = 1`.
5. `5 < 10` → another starts: `count = 2`, `res = 2`.
6. `15 < 10` is false → the earliest meeting has ended: `e += 1`, `count = 1`.
7. `15 < 20` → a new one starts: `count = 2`. All starts are used up, so the loop stops. Answer → `2`.

Once every meeting has started, the count can only go down, so the loop can stop at that point. O(n log n) time (sorting), O(n) space.
