# 338. Counting Bits
LeetCode: https://leetcode.com/problems/counting-bits/ · Easy · Pattern: Dynamic programming + bits

## Problem
Given a number `n`, return a list of length `n + 1` where item `i` is **how many `1`s are in the binary form of `i`**.

```
Input: n = 4
Output: [0, 1, 1, 2, 1]
   0 = 0        → zero 1s
   1 = 1        → one 1
   2 = 10       → one 1
   3 = 11       → two 1s
   4 = 100      → one 1
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary** | Writing numbers using only 0 and 1. 5 in binary is `101` (= 4 + 0 + 1). |
| **bit** | A single binary digit (a 0 or a 1). |
| **power of two** | 1, 2, 4, 8, 16, ... In binary each one is a single `1` followed by zeros: `1`, `10`, `100`, `1000`. |
| **dynamic programming (DP)** | Use answers you've already worked out for smaller numbers. `dp[i]` = the answer for `i`. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** For every number, convert it to binary and count the 1s. Works, but each count takes work.

**Step 2: notice a pattern.** Look at 6 = `110`. Remove its leading `1` and you get `10` = 2. So `bits(6) = 1 + bits(2)`. In general, every number is **(the biggest power of two that fits in it) + (a smaller number)**:

| Number | Binary | = power of two + smaller | bits |
|---|---|---|---|
| 5 | `101` | 4 + 1 | 1 + bits(1) |
| 6 | `110` | 4 + 2 | 1 + bits(2) |
| 7 | `111` | 4 + 3 | 1 + bits(3) |

**Step 3: turn it into a formula.** Let `offset` be the biggest power of two that is ≤ `i`. Then
> **dp[i] = 1 + dp[i − offset]**

`dp[i − offset]` is a smaller number, so its answer is **already in the list**.

**Step 4: when does `offset` change?** Each time `i` reaches the next power of two (`offset × 2`).

## Solution
```python
class Solution:
    def countBits(self, n: int) -> List[int]:
        dp = [0] * (n + 1)
        offset = 1

        for i in range(1, n + 1):
            if offset * 2 == i:
                offset = i
            dp[i] = 1 + dp[i - offset]

        return dp
```

## Line by line
| Line | What it does |
|---|---|
| `dp = [0] * (n + 1)` | A list of `n + 1` zeros. `dp[0]` is correctly 0 (zero has no 1s). |
| `offset = 1` | The biggest power of two ≤ the current `i`. |
| `for i in range(1, n + 1):` | Fill in the answer for 1, 2, 3, ..., `n`. |
| `if offset * 2 == i:` | Have we reached the next power of two? |
| `offset = i` | Yes → update `offset`. |
| `dp[i] = 1 + dp[i - offset]` | One `1` for the power of two, plus the (already known) count for the leftover. |
| `return dp` | The finished list. |

## Watch it run
`n = 8`

| `i` | Binary | `offset` | `i − offset` | `dp[i] = 1 + dp[i − offset]` |
|---|---|---|---|---|
| 0 | `0` | | | 0 (given) |
| 1 | `1` | 1 | 0 | 1 + dp[0] = **1** |
| 2 | `10` | 2 (since 1×2 = 2) | 0 | 1 + dp[0] = **1** |
| 3 | `11` | 2 | 1 | 1 + dp[1] = **2** |
| 4 | `100` | 4 (since 2×2 = 4) | 0 | 1 + dp[0] = **1** |
| 5 | `101` | 4 | 1 | 1 + dp[1] = **2** |
| 6 | `110` | 4 | 2 | 1 + dp[2] = **2** |
| 7 | `111` | 4 | 3 | 1 + dp[3] = **3** |
| 8 | `1000` | 8 (since 4×2 = 8) | 0 | 1 + dp[0] = **1** |

Answer: `[0, 1, 1, 2, 1, 2, 2, 3, 1]` ✅

## How fast is it?
- **Time: O(n).** Each number takes one quick step.
- **Space: O(n).** The answer list.
