# 338. Counting Bits
LeetCode: https://leetcode.com/problems/counting-bits/ · Easy · Pattern: Dynamic programming + bits

## Problem
Given an integer `n`, return an array `ans` of length `n + 1` where `ans[i]` is the number of `1` bits in the binary representation of `i`.

**Example**
```
Input: n = 4
Output: [0,1,1,2,1]      (0=0, 1=1, 2=10, 3=11, 4=100)
```

## Solution
```python
class Solution:
    def countBits(self, n: int) -> List[int]:
        dp = [0] * (n + 1)
        offset = 1

        for i in range(1, n + 1):
            if offset * 2 == i:
                offset = i
            dp[i] = 1 + dp[i - offset]

        return dp
```

Using `n = 4`:

1. Counting bits for each number separately works, but there's a shortcut: every number is **the largest power of two ≤ it, plus a smaller number**. For example `6 = 4 + 2` (`110` = `100` + `10`), so `bits(6) = 1 + bits(2)`.
2. `offset` is that largest power of two so far. It starts at 1.
3. When `i` reaches `offset * 2`, a new power of two begins, so `offset = i`.
4. `dp[i] = 1 + dp[i - offset]`: one bit for the power of two, plus the already-computed answer for the remainder.
5. `dp[0] = 0`. Then:
   - i=1: `dp[1] = 1 + dp[0] = 1`
   - i=2: `2 == 1*2` → `offset = 2`; `dp[2] = 1 + dp[0] = 1`
   - i=3: `dp[3] = 1 + dp[1] = 2`
   - i=4: `4 == 2*2` → `offset = 4`; `dp[4] = 1 + dp[0] = 1`
6. Result → `[0,1,1,2,1]`.

Reusing earlier answers means each number takes O(1): O(n) total time, O(n) space for the output.
