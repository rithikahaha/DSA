# 242. Valid Anagram
LeetCode: https://leetcode.com/problems/valid-anagram/ · Easy · Pattern: Hash map (counting)

## Problem
Given two strings `s` and `t`, return `true` if `t` is an anagram of `s` (same letters, same counts, any order), otherwise `false`.

**Example 1**
```
Input: s = "racecar", t = "carrace"
Output: true
```

**Example 2**
```
Input: s = "jar", t = "jam"
Output: false
```

## Solution
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        countS, countT = {}, {}
        for i in range(len(s)):
            countS[s[i]] = 1 + countS.get(s[i], 0)
            countT[t[i]] = 1 + countT.get(t[i], 0)
        for c in countS:
            if countS[c] != countT.get(c, 0):
                return False

        return True
```

Using `s = "jar"`, `t = "jam"`:

1. Different lengths can never be anagrams, so return `False` right away.
2. Build a letter→count dictionary for each string in one loop. `.get(x, 0)` returns 0 for a letter not seen yet, so `1 + .get(...)` starts a new count at 1.
3. `countS = {j:1, a:1, r:1}` and `countT = {j:1, a:1, m:1}`.
4. Check every letter of `s`: `r` has count 1 in `s` but `countT.get('r', 0)` is 0 → mismatch → `False`.
5. Both lengths are equal and every count matches → `True`.

Sorting both strings and comparing also works (O(n log n)). Counting is O(n) time and O(1) space, since there are at most 26 letters.
