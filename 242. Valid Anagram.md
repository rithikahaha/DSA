# 242. Valid Anagram
LeetCode: https://leetcode.com/problems/valid-anagram/ · Easy · Pattern: Hash map (counting)

## Problem
Given two strings `s` and `t`, return `True` if `t` is an **anagram** of `s`: the same letters, the same number of each, in any order.

```
Input: s = "racecar", t = "carrace"     Output: True
Input: s = "jar",     t = "jam"         Output: False
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **anagram** | A word rearranged. "listen" and "silent" use exactly the same letters. |
| **dictionary** | A phone book: look something up by its "name" (the **key**) and get its "number" (the **value**). Here: key = a letter, value = how many times it appears. Written like `{"a": 2, "b": 1}`. |
| **`.get(x, 0)`** | "Look up `x` in the dictionary, but if it isn't there, give me 0 instead of crashing." |

## How to come up with it (the thinking)
**Step 1: what does "same letters" really mean?** Every letter must appear the **same number of times** in both words.

**Step 2: turn it into counting.** Make a tally for each word (like tally marks): `jar` → j:1, a:1, r:1. Then compare the two tallies. If they match, it's an anagram.

**Step 3: an easy early exit.** If the two words have **different lengths**, they can't possibly match, so answer `False` immediately.

## Solution
```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False

        countS, countT = {}, {}
        for i in range(len(s)):
            countS[s[i]] = 1 + countS.get(s[i], 0)
            countT[t[i]] = 1 + countT.get(t[i], 0)
        for c in countS:
            if countS[c] != countT.get(c, 0):
                return False

        return True
```

## Line by line
| Line | What it does |
|---|---|
| `if len(s) != len(t): return False` | Different lengths → can't be anagrams. Stop early. |
| `countS, countT = {}, {}` | Two empty tally sheets, one per word. |
| `for i in range(len(s)):` | Go through positions 0, 1, 2, ... of the words. |
| `countS[s[i]] = 1 + countS.get(s[i], 0)` | Take the letter at position `i` of `s`. Its new tally is 1 + its old tally (or 1 + 0 if we've never seen it). |
| `countT[t[i]] = ...` | Same thing for `t`. |
| `for c in countS:` | Now go through each letter in the first tally. |
| `if countS[c] != countT.get(c, 0):` | Does the second word have the same number of this letter? (0 if it doesn't have it at all.) |
| `return False` | A mismatch was found → not an anagram. |
| `return True` | Every letter matched → anagram. |

## Watch it run
`s = "jar"`, `t = "jam"` (same length, so we continue)

| `i` | `s[i]` | `t[i]` | `countS` after | `countT` after |
|---|---|---|---|---|
| 0 | j | j | `{j:1}` | `{j:1}` |
| 1 | a | a | `{j:1, a:1}` | `{j:1, a:1}` |
| 2 | r | m | `{j:1, a:1, r:1}` | `{j:1, a:1, m:1}` |

Now compare each letter in `countS`:

| `c` | `countS[c]` | `countT.get(c, 0)` | Same? |
|---|---|---|---|
| j | 1 | 1 | Yes |
| a | 1 | 1 | Yes |
| r | 1 | **0** (no `r` in `jam`) | **No** → return `False` |

## How fast is it?
- **Time: O(n).** One walk through the letters.
- **Space: O(1).** There are at most 26 different letters, so the tallies stay small however long the words are.
