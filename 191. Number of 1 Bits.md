# 191. Number of 1 Bits
LeetCode: https://leetcode.com/problems/number-of-1-bits/ · Easy · Pattern: Bit manipulation

## Problem
Given a positive integer `n`, return the number of `1` bits in its binary representation (its Hamming weight).

**Example 1**
```
Input: n = 23      (binary 10111)
Output: 4
```

**Example 2**
```
Input: n = 128     (binary 10000000)
Output: 1
```

## Solution
```python
class Solution:
    def hammingWeight(self, n: int) -> int:
        res = 0
        while n:
            res += n % 2
            n = n >> 1
        return res
```

Using `n = 5` (binary `101`):

1. `n % 2` is the **last bit**: 1 if `n` is odd, 0 if even. Add it to the count.
2. `n >> 1` shifts every bit one place to the right, which drops the last bit and exposes the next one (it's the same as `n // 2`).
3. Repeat until `n` becomes 0, when no `1`s remain.
4. `n = 5` (`101`): last bit 1 → `res = 1`, `n = 2` (`10`).
5. Last bit 0 → `res = 1`, `n = 1` (`1`).
6. Last bit 1 → `res = 2`, `n = 0`. The loop ends → `2`.

It loops once per bit, so it's O(log n) time and O(1) space. `n & 1` does the same job as `n % 2`.
