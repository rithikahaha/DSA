# 191. Number of 1 Bits
LeetCode: https://leetcode.com/problems/number-of-1-bits/ · Easy · Pattern: Bit manipulation

## Problem
Given a positive number `n`, count **how many `1`s** appear in its binary form.

```
Input: n = 23     (binary 10111)     Output: 4
Input: n = 128    (binary 10000000)  Output: 1
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary** | Writing numbers with only 0s and 1s. 5 is `101` because 5 = 4 + 0 + 1. |
| **bit** | One binary digit. `101` has three bits. |
| **`n % 2`** | The remainder when dividing by 2. It's 1 if `n` is odd, 0 if even. In binary, that's the **last bit**. |
| **`n >> 1`** (right shift) | Slide every bit one place to the right, dropping the last bit. `101` becomes `10`. It's the same as dividing by 2 and dropping the remainder. |

## How to come up with it (the thinking)
**Step 1: how do we look at one bit?** The last bit tells us if the number is odd: `n % 2` is 1 when the last bit is 1.

**Step 2: how do we look at the next bit?** Shift right (`n >> 1`). The last bit falls off and the second-to-last bit becomes the new last bit.

**Step 3: combine.** Repeat: check the last bit (add it to the count), shift right. Stop when the number becomes 0, since then no 1s remain.

## Solution
```python
class Solution:
    def hammingWeight(self, n: int) -> int:
        res = 0
        while n:
            res += n % 2
            n = n >> 1
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `res = 0` | Count of 1s so far. |
| `while n:` | Keep going while `n` isn't 0 (`0` counts as "false"). |
| `res += n % 2` | Add the last bit: +1 if it's a 1, +0 if it's a 0. |
| `n = n >> 1` | Drop the last bit, exposing the next one. |
| `return res` | The total number of 1s. |

## Watch it run
`n = 5` (binary `101`)

| Loop | `n` (binary) | Last bit `n % 2` | `res` after | `n >> 1` becomes |
|---|---|---|---|---|
| 1 | `101` | 1 | 1 | `10` (2) |
| 2 | `10` | 0 | 1 | `1` (1) |
| 3 | `1` | 1 | 2 | `0` |

`n` is 0, so the loop stops. Answer: **2** ✅

## How fast is it?
- **Time: O(log n).** One loop per bit, and a number `n` has about log₂(n) bits.
- **Space: O(1).**
