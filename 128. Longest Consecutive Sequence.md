# 128. Longest Consecutive Sequence
LeetCode: https://leetcode.com/problems/longest-consecutive-sequence/ · Medium · Pattern: Hash set

## Problem
Given an unsorted list `nums`, find the length of the **longest run of consecutive numbers** (like 2, 3, 4, 5). The numbers can be anywhere in the list, in any order. It must run in O(n).

```
Input:  nums = [2, 20, 4, 10, 3, 4, 5]
Output: 4       (the run 2, 3, 4, 5)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **consecutive** | Each number is exactly 1 more than the last: 7, 8, 9. |
| **set** | A bag that holds each item once and answers "is it in here?" instantly. |
| **start of a run** | A number whose "one below" isn't in the list. 2 is a start (there's no 1), but 3 is not (2 exists). |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Sort the list, then scan for runs. It works, but sorting is O(n log n), slower than the O(n) required.

**Step 2: another idea.** For every number, count upwards (n+1, n+2, ...) while those numbers exist. Checking "does n+1 exist?" is instant with a set. But if we do this from *every* number, we repeat work: from 2 we count 2,3,4,5, and then from 3 we count 3,4,5 again.

**Step 3: the trick.** Only start counting from the **beginning of a run**. A number is a beginning if `n - 1` is **not** in the set. Now every run is counted exactly once, from its first number.

## Solution
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        numSet = set(nums)
        longest = 0

        for n in nums:
            if (n - 1) not in numSet:
                length = 0
                while (n + length) in numSet:
                    length += 1
                longest = max(length, longest)
        return longest
```

## Line by line
| Line | What it does |
|---|---|
| `numSet = set(nums)` | Put all numbers in a set (also removes duplicates). |
| `longest = 0` | Best run length found so far. |
| `for n in nums:` | Look at each number. |
| `if (n - 1) not in numSet:` | Is the number just below missing? If yes, `n` is the **start** of a run. Otherwise skip it. |
| `length = 0` | Start counting this run from zero. |
| `while (n + length) in numSet:` | Does `n`, then `n+1`, then `n+2`... exist? Keep going while yes. |
| `length += 1` | One more number in the run. |
| `longest = max(length, longest)` | Keep the larger of the old best and this run. |

## Watch it run
`nums = [2, 20, 4, 10, 3, 4, 5]` → set = `{2, 3, 4, 5, 10, 20}`

| `n` | Is `n-1` in the set? | Start? | Counting | `length` | `longest` |
|---|---|---|---|---|---|
| 2 | 1: no | **Yes** | 2✓ 3✓ 4✓ 5✓ 6✗ | 4 | 4 |
| 20 | 19: no | **Yes** | 20✓ 21✗ | 1 | 4 |
| 4 | 3: yes | No, skip | | | 4 |
| 10 | 9: no | **Yes** | 10✓ 11✗ | 1 | 4 |
| 3 | 2: yes | No, skip | | | 4 |
| 4 | 3: yes | No, skip | | | 4 |
| 5 | 4: yes | No, skip | | | 4 |

Answer: **4** ✅

## How fast is it?
- **Time: O(n).** Skipping non-starts means each number is counted at most once across the whole run of the program.
- **Space: O(n).** The set.
