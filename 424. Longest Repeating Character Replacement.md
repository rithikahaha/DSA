# 424. Longest Repeating Character Replacement
LeetCode: https://leetcode.com/problems/longest-repeating-character-replacement/ · Medium · Pattern: Sliding window

## Problem
Given an uppercase string `s` and a number `k`, you may **change at most `k` letters** to any other letter. Return the **length of the longest substring** you can turn into one repeated letter (like `AAAAA`).

```
Input: s = "XYYX",    k = 2     Output: 4     (change both X's to Y)
Input: s = "AAABABB", k = 1     Output: 5     ("AAABA" → change the B into A)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **substring** | A continuous piece of the string. |
| **sliding window** | A frame from position `l` to position `r` that we grow (move `r`) and shrink (move `l`). |
| **`count`** | A dictionary that tallies how many of each letter are **inside the window**. |
| **`maxf`** | "Max frequency": the highest tally of any single letter in the window. |

## How to come up with it (the thinking)
**Step 1: ask what a window needs to be "good".** A window can become all one letter if we can afford to change everything that isn't the most common letter. Take `AAABA`: `A` is the majority (4 of 5), so we only need to change the 1 other letter.

**Step 2: turn that into a formula.**
> letters to change = **window length − count of the most common letter**

The window is **good** when that number is `<= k`.

**Step 3: the sliding-window plan.** Grow the window by moving `r` right, and update the tallies. If the window has become **bad** (needs more than `k` changes), shrink it by moving `l` right (and remove that letter from the tally) until it's good again. Record the longest good window.

**Step 4: a small shortcut.** We never lower `maxf` when we shrink. That's fine: the window can only beat the current best if `maxf` rises, so an old, too-high `maxf` can never make us report a wrong answer.

## Solution
```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        count = {}
        res = 0

        l = 0
        maxf = 0
        for r in range(len(s)):
            count[s[r]] = 1 + count.get(s[r], 0)
            maxf = max(maxf, count[s[r]])

            while (r - l + 1) - maxf > k:
                count[s[l]] -= 1
                l += 1

            res = max(res, r - l + 1)
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `count = {}` | Tally of letters in the window. |
| `res = 0` | Longest good window so far. |
| `l = 0`, `maxf = 0` | Left edge, and the highest single-letter tally. |
| `for r in range(len(s)):` | Move the right edge along the string. |
| `count[s[r]] = 1 + count.get(s[r], 0)` | The new letter enters the window → add 1 to its tally. |
| `maxf = max(maxf, count[s[r]])` | Has this letter become the new most common one? |
| `while (r - l + 1) - maxf > k:` | Window length minus majority count = letters to change. More than `k`? The window is bad. |
| `count[s[l]] -= 1` | Remove the leftmost letter from the tally... |
| `l += 1` | ...and move the left edge right. Repeat until good. |
| `res = max(res, r - l + 1)` | Record the window length if it's the best yet. |

Answer: **5** ✅

## How fast is it?
- **Time: O(n).** Each edge moves along the string once.
- **Space: O(1).** At most 26 letters in the tally.
