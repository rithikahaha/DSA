# 235. Lowest Common Ancestor of a Binary Search Tree
LeetCode: https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-search-tree/ · Medium · Pattern: BST navigation

## Problem
In a **binary search tree**, given two nodes `p` and `q`, find their **lowest common ancestor**: the lowest (deepest) node that has both `p` and `q` somewhere below it. A node counts as being below itself.

```
          5
        /   \
       3     8
      / \   / \
     1   4 7   9

p = 3, q = 8   →   5
p = 7, q = 9   →   8
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary search tree (BST)** | A tree where, for every node, **everything on its left is smaller** and **everything on its right is bigger**. |
| **ancestor** | A node above you on the path up to the root. |
| **lowest common ancestor (LCA)** | The lowest node that is an ancestor of both `p` and `q`, where their paths from the root part ways. |
| **`.val`** | The number stored in a node. |

## How to come up with it (the thinking)
**Step 1: use the BST rule.** Start at the root and ask where `p` and `q` live:
- **Both are bigger** than the current node → they're both in the **right** subtree. The answer is down there, so move right.
- **Both are smaller** → they're both in the **left** subtree. Move left.

**Step 2: when do we stop?** When they are **not** both on the same side: one is smaller and one is bigger (or one of them *is* the current node). The path to `p` and the path to `q` split here, so this node is the lowest one they share.

**Step 3: no recursion needed.** We're just walking down one path, so a simple loop with a marker `cur` is enough.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        cur = root

        while cur:
            if p.val > cur.val and q.val > cur.val:
                cur = cur.right
            elif p.val < cur.val and q.val < cur.val:
                cur = cur.left
            else:
                return cur
```

## Line by line
| Line | What it does |
|---|---|
| `cur = root` | Start at the top. |
| `while cur:` | Keep walking while we're on a real node. |
| `if p.val > cur.val and q.val > cur.val:` | Are **both** bigger than the current node? |
| `cur = cur.right` | Yes → both are in the right subtree, so step right. |
| `elif p.val < cur.val and q.val < cur.val:` | Are **both** smaller? |
| `cur = cur.left` | Yes → step left. |
| `else: return cur` | Neither → they split here (or one equals `cur`). This is the LCA. |

## Watch it run
Using the tree above.

**`p = 3`, `q = 8`:**

| `cur` | 3 vs `cur` | 8 vs `cur` | Both same side? | Action |
|---|---|---|---|---|
| 5 | smaller | bigger | **No** (split) | return **5** |

**`p = 7`, `q = 9`:**

| `cur` | 7 vs `cur` | 9 vs `cur` | Both same side? | Action |
|---|---|---|---|---|
| 5 | bigger | bigger | Yes, both right | `cur = 8` |
| 8 | smaller | bigger | **No** (split) | return **8** |

## How fast is it?
- **Time: O(h).** We walk down a single path (h = height of the tree).
- **Space: O(1).** Only the `cur` marker.
