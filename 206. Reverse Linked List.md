# 206. Reverse Linked List
LeetCode: https://leetcode.com/problems/reverse-linked-list/ · Easy · Pattern: Linked list (prev / curr / next)

## Problem
Given the head of a singly linked list, reverse it and return the new head.

**Example**
```
Input: head = [0,1,2,3]
Output: [3,2,1,0]
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev, curr = None, head

        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        return prev
```

Using `1 → 2 → 3`:

1. `prev` is the already-reversed part (starts empty, `None`) and `curr` is the node being processed.
2. **Save the rest first:** `nxt = curr.next`. Once you change `curr.next`, you'd otherwise lose the rest of the list.
3. **Flip the arrow:** `curr.next = prev`, so the node now points backwards.
4. **Step forward:** `prev = curr`, then `curr = nxt`.
5. Loop 1: `None ← 1`, remaining `2 → 3`. Loop 2: `None ← 1 ← 2`, remaining `3`. Loop 3: `None ← 1 ← 2 ← 3`.
6. `curr` is now `None`, and `prev` sits on the last node, which is the new head → return `prev`.

The reversal is done in place: O(n) time, O(1) space. Recursion also works but uses O(n) stack space.
