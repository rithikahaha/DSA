# 206. Reverse Linked List
LeetCode: https://leetcode.com/problems/reverse-linked-list/ · Easy · Pattern: Linked list (prev / curr / next)

## Problem
You're given the first node (the **head**) of a linked list. Reverse the list and return the new first node.

```
Input:  0 → 1 → 2 → 3
Output: 3 → 2 → 1 → 0
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **linked list** | A chain of people holding hands in a line. Each person (a **node**) knows only their own name (`val`) and **who is next in line** (`next`). Nobody knows the whole line. |
| **head** | The first person in the line. |
| **`None`** | "Nobody". The last person's `next` is `None`, meaning the line ends. |
| **pointer** | Just a name for "who I'm pointing at". `curr.next` means "the person `curr` is pointing to". |

You can't jump to the 3rd person directly. You must start at the head and follow the `next` links one at a time.

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Copy all the values into a normal list, reverse that, and build a new chain. That works, but we're building a whole new chain (extra memory).

**Step 2: the better idea.** Don't move the people. Just **flip who each person points at**. Right now 0 points at 1. Make 1 point at 0 instead. Then 2 points at 1, and so on. Every arrow gets turned around.

**Step 3: the catch.** Say we're standing on person 1 and want them to point *backwards* at 0. The moment we change 1's `next`, we **lose** the link to 2, and the rest of the chain is gone. So before flipping, we first **write down who is next** in a spare variable.

**Step 4: what we need to track.** Three things:
- `curr`: the person we're working on right now,
- `prev`: the person just behind us (who `curr` will point at after flipping),
- `nxt`: the saved "who's next", so we don't lose the chain.

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        prev, curr = None, head

        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        return prev
```

## Line by line
| Line | What it does |
|---|---|
| `prev, curr = None, head` | `curr` starts at the first person. `prev` is `None` because nobody is behind the first person. The old first person will end up **last**, pointing at `None`. |
| `while curr:` | Keep going as long as there's a person to process. When `curr` becomes `None`, we've walked off the end. |
| `nxt = curr.next` | **Save** who's next before we break the link. |
| `curr.next = prev` | **Flip the arrow.** The current person now points backwards. |
| `prev = curr` | Step forward: the person we just finished becomes the "one behind". |
| `curr = nxt` | Step forward: move to the saved next person. |
| `return prev` | When the loop ends, `curr` is `None` and `prev` is the last person we processed. That person is the **new head**. |

Lines 3 to 6 always go in this order. Swapping them loses part of the chain.

## Watch it run
Start: `0 → 1 → 2 → 3`, with `prev = None`, `curr = 0`.

| Loop | `curr` | `nxt` (saved) | Flip: `curr.next =` | `prev` after | `curr` after | Reversed part so far |
|---|---|---|---|---|---|---|
| 1 | 0 | 1 | `None` | 0 | 1 | `None ← 0` |
| 2 | 1 | 2 | `0` | 1 | 2 | `None ← 0 ← 1` |
| 3 | 2 | 3 | `1` | 2 | 3 | `None ← 0 ← 1 ← 2` |
| 4 | 3 | `None` | `2` | 3 | `None` | `None ← 0 ← 1 ← 2 ← 3` |

Now `curr` is `None`, so the loop stops. `prev` is 3 → return it. Following the arrows from 3 gives `3 → 2 → 1 → 0`. ✅

## How fast is it?
- **Time: O(n).** Each person is visited exactly once.
- **Space: O(1).** We only use three spare variables (`prev`, `curr`, `nxt`), no matter how long the list is.
