# 217. Contains Duplicate
LeetCode: https://leetcode.com/problems/contains-duplicate/ · Easy · Pattern: Hash set

## Problem
Given an integer array `nums`, return `true` if any value appears at least twice, and `false` if every element is distinct.

**Example 1**
```
Input: nums = [1,2,3,3]
Output: true
```

**Example 2**
```
Input: nums = [1,2,3,4]
Output: false
```

## Solution
```python
class Solution:
    def hasDuplicate(self, nums: List[int]) -> bool:
        hashset = set()
        for n in nums:
            if n in hashset:
                return True
            hashset.add(n)
        return False
```

Using `nums = [1,2,3,3]`:

1. `hashset` holds every number seen so far. A set answers "is it in here?" in O(1).
2. n=1, 2, 3: none are in the set yet, so each gets added → `{1,2,3}`.
3. n=3 again: it's already in the set → return `True`.
4. If the loop finishes without a repeat, no duplicates exist → `False`.

Brute force compares every pair, O(n²). Sorting first and comparing neighbours is O(n log n). The set is a single pass: O(n) time, O(n) space.
