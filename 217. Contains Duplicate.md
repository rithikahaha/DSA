# 217. Contains Duplicate
LeetCode: https://leetcode.com/problems/contains-duplicate/ · Easy · Pattern: Hash set

## Problem
You get a list of numbers `nums`. Return `True` if **any number appears more than once**, and `False` if every number is different.

```
Input:  nums = [1, 2, 3, 3]     Output: True     (3 appears twice)
Input:  nums = [1, 2, 3, 4]     Output: False
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **set** | A bag that stores each item **only once** and can tell you *instantly* whether something is already inside. Adding a 3 twice still leaves one 3. |
| **duplicate** | A value that shows up again. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Take the first number and compare it with every other number. Then the second number, and so on. With 1,000 numbers that's about 500,000 comparisons.

**Step 2: what's wasteful?** We keep re-reading numbers we've already looked at.

**Step 3: the trick.** Walk through the list once, carrying a bag of "numbers I've already seen". For each new number ask the bag: *"Have I seen you before?"* If yes, that's a duplicate. If no, drop it in the bag and move on.

## Solution
```python
class Solution:
    def hasDuplicate(self, nums: List[int]) -> bool:
        hashset = set()
        for n in nums:
            if n in hashset:
                return True
            hashset.add(n)
        return False
```

## Line by line
| Line | What it does |
|---|---|
| `hashset = set()` | Make an empty bag. |
| `for n in nums:` | Look at the numbers one at a time; `n` is the current one. |
| `if n in hashset:` | Ask the bag: "Is `n` already in here?" |
| `return True` | Yes, so we've seen it before. That's a duplicate. Stop and answer `True`. |
| `hashset.add(n)` | Not seen yet, so put it in the bag for next time. |
| `return False` | We checked every number and never found a repeat. |

## Watch it run
`nums = [1, 2, 3, 3]`

| Step | `n` | Bag before | Is `n` in the bag? | What happens |
|---|---|---|---|---|
| 1 | 1 | `{}` | No | Add → `{1}` |
| 2 | 2 | `{1}` | No | Add → `{1,2}` |
| 3 | 3 | `{1,2}` | No | Add → `{1,2,3}` |
| 4 | 3 | `{1,2,3}` | **Yes** | Return `True` |

## How fast is it?
- **Time: O(n).** One walk through the list; each bag check is instant.
- **Space: O(n).** The bag may end up holding every number.
