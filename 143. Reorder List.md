# 143. Reorder List
LeetCode: https://leetcode.com/problems/reorder-list/ · Medium · Pattern: Find middle + reverse + merge

## Problem
Rearrange a linked list **in place** so it goes: first, last, second, second-to-last, and so on. Don't return anything.

```
Input:  1 → 2 → 3 → 4          Output: 1 → 4 → 2 → 3
Input:  2 → 4 → 6 → 8 → 10     Output: 2 → 10 → 4 → 8 → 6
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **linked list** | A chain of people holding hands; each **node** knows only who is next (`next`). We can only walk forward. |
| **slow / fast pointer** | Two markers: `slow` moves 1 step, `fast` moves 2. When `fast` reaches the end, `slow` is at the **middle**. |
| **in place** | Change the existing chain instead of building a new one. |

## How to come up with it (the thinking)
**Step 1: what's the pattern?** We alternate: one from the **front**, one from the **back**. The trouble is that in a linked list we can't walk backwards to grab the last node.

**Step 2: fix the "can't go backwards" problem.** Split the list into two halves and **reverse the second half**. Now walking the reversed half gives us the back nodes in the order we need.

**Step 3: assemble.** The whole solution is three smaller jobs (you may have solved them already):
1. **Find the middle** (slow/fast pointers).
2. **Reverse the second half** (problem 206).
3. **Weave** the two halves together: one node from the first half, one from the reversed second half, alternating.

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        second = slow.next
        slow.next = None
        prev = slow.next = None
        while second:
            tmp = second.next
            second.next = prev
            prev = second
            second = tmp

        first, second = head, prev
        while second:
            tmp1, tmp2 = first.next, second.next
            first.next = second
            second.next = tmp1
            first, second = tmp1, tmp2
```

## Line by line
**Job 1: find the middle**

| Line | What it does |
|---|---|
| `slow, fast = head, head.next` | `slow` at the first node, `fast` one ahead. |
| `while fast and fast.next:` | Repeat while `fast` can still take two steps. |
| `slow = slow.next; fast = fast.next.next` | `slow` moves 1, `fast` moves 2. When the loop ends, `slow` is the last node of the first half. |

**Job 2: cut and reverse the second half**

| Line | What it does |
|---|---|
| `second = slow.next` | The start of the second half. |
| `slow.next = None` | Cut the chain in two, so the first half now ends. |
| `prev = slow.next = None` | Set `prev` to `None` (the reversing needs it to start empty). |
| `while second:` | Walk the second half. |
| `tmp = second.next` | **Save** who's next before flipping. |
| `second.next = prev` | Flip the arrow backwards. |
| `prev = second; second = tmp` | Step forward. When done, `prev` is the head of the reversed half. |

**Job 3: weave the halves together**

| Line | What it does |
|---|---|
| `first, second = head, prev` | `first` walks the first half; `second` walks the reversed second half. |
| `while second:` | Continue while the second half has nodes. |
| `tmp1, tmp2 = first.next, second.next` | **Save** both "who's next"s, since we're about to change links. |
| `first.next = second` | First-half node now points to a second-half node. |
| `second.next = tmp1` | That second-half node points to the *next* first-half node. |
| `first, second = tmp1, tmp2` | Move both markers forward. |

## Watch it run
`1 → 2 → 3 → 4`

**Job 1:** `slow = 1`, `fast = 2`. Fast can move (2 has a next): `slow = 2`, `fast = 4`. `fast.next` is `None`, so stop. `slow` = node 2.

**Job 2:** `second = 3`, cut → first half `1 → 2`, second half `3 → 4`. Reverse it:

| Loop | `second` | Saved `tmp` | After flip | `prev` |
|---|---|---|---|---|
| 1 | 3 | 4 | `None ← 3` | 3 |
| 2 | 4 | `None` | `None ← 3 ← 4` | 4 |

Reversed second half: `4 → 3`.

**Job 3:** `first = 1`, `second = 4`.

| Round | Saved `tmp1`, `tmp2` | Relinking | List so far |
|---|---|---|---|
| 1 | 2, 3 | `1 → 4 → 2` | `1 → 4 → 2 → ...` |
| 2 | `None`, `None` | `2 → 3` | `1 → 4 → 2 → 3` |

Final: `1 → 4 → 2 → 3` ✅

## How fast is it?
- **Time: O(n).** Three simple passes.
- **Space: O(1).** Only a few markers; nodes are relinked in place.
