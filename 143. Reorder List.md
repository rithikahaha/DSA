# 143. Reorder List
LeetCode: https://leetcode.com/problems/reorder-list/ · Medium · Pattern: Find middle + reverse + merge

## Problem
Given the head of a singly linked list `L0 → L1 → ... → Ln`, reorder it **in place** into `L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → ...`. Don't return anything.

**Example**
```
Input: head = [2,4,6,8]
Output: [2,8,4,6]

Input: head = [2,4,6,8,10]
Output: [2,10,4,8,6]
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def reorderList(self, head: Optional[ListNode]) -> None:
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        second = slow.next
        slow.next = None
        prev = slow.next = None
        while second:
            tmp = second.next
            second.next = prev
            prev = second
            second = tmp

        first, second = head, prev
        while second:
            tmp1, tmp2 = first.next, second.next
            first.next = second
            second.next = tmp1
            first, second = tmp1, tmp2
```

Using `1 → 2 → 3 → 4`:

1. The target order takes one node from the front, then one from the back, alternating. A singly linked list can't walk backwards, so reverse the second half first. This problem is three earlier tricks glued together.
2. **Find the middle** with slow/fast pointers (fast moves two per step). The middle here is node `2`.
3. **Cut the list in two:** `second = slow.next` (starts at `3`), then `slow.next = None`, giving `1 → 2` and `3 → 4`.
4. **Reverse the second half** with the prev/curr/next trick (see problem 206): `4 → 3`, with `prev` ending as its head.
5. **Weave the halves together.** Save both `next`s first (`tmp1`, `tmp2`) so nothing is lost. Then `first.next = second` and `second.next = tmp1`. Then step: `first, second = tmp1, tmp2`.
   - `1 → 4 → 2`, then `2 → 3`. Final: `1 → 4 → 2 → 3`.

Three linear passes: O(n) time, O(1) space.
