# DSA Practice

NeetCode / LeetCode problems in Python. Each file is written for beginners and has: the **problem**, the **words you need first**, **how to come up with the idea**, the **solution**, a **line-by-line explanation**, a **table that traces the code running**, and the **time/space cost** in plain English.

## How to think about a new problem

1. **What's the brute force?** (Usually "check every pair" = slow.)
2. **What work am I repeating?** The pattern is the trick that removes that repeat.
3. **Match the input to a pattern** using the sections below.
4. **Draw a tiny example by hand** and write each step you take. That *is* the algorithm.
5. **Re-solve it from a blank page after 2-3 days.** If you can't, you memorised it instead of learning it.
