# 21. Merge Two Sorted Lists
LeetCode: https://leetcode.com/problems/merge-two-sorted-lists/ · Easy · Pattern: Linked list (dummy node)

## Problem
You get two **sorted linked lists**. Join them into **one sorted linked list** and return its first node.

```
list1: 1 → 2 → 4
list2: 1 → 3 → 5
Output: 1 → 1 → 2 → 3 → 4 → 5
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **linked list** | A chain of people holding hands. Each **node** knows its own value (`val`) and who is next (`next`). The chain ends with `None` ("nobody"). |
| **head** | The first node. |
| **dummy node** | A fake placeholder node we put at the very front, just so we never have to ask "what is the first node of the merged list?". |
| **`tail`** | A marker that always points at the **last node of the merged list so far**, where we attach the next node. |

## How to come up with it (the thinking)
**Step 1: think of two sorted piles of cards.** To make one sorted pile, look at the top card of each pile, take the **smaller** one, and put it on the new pile. Repeat.

**Step 2: do that with the chain.** Compare the heads of both lists. Attach the smaller node to the end of our new chain (`tail.next = that node`), then step forward in that list.

**Step 3: the awkward part.** The first node we attach has nothing to attach *to*. A dummy node solves this: start the new chain as `dummy`, attach everything after it, and at the end return `dummy.next`.

**Step 4: leftovers.** When one list runs out, the other list is already sorted, so attach whatever is left of it in one go.

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        tail = dummy

        while l1 and l2:
            if l1.val < l2.val:
                tail.next = l1
                l1 = l1.next
            else:
                tail.next = l2
                l2 = l2.next
            tail = tail.next

        if l1:
            tail.next = l1
        elif l2:
            tail.next = l2

        return dummy.next
```

## Line by line
| Line | What it does |
|---|---|
| `dummy = ListNode()` | Create the fake starting node. |
| `tail = dummy` | The new chain currently ends at the dummy. |
| `while l1 and l2:` | Keep going while **both** lists still have nodes. |
| `if l1.val < l2.val:` | Is list 1's front node smaller? |
| `tail.next = l1` | Yes → attach it to the end of the new chain... |
| `l1 = l1.next` | ...and step forward in list 1. |
| `else: tail.next = l2; l2 = l2.next` | Otherwise do the same with list 2. |
| `tail = tail.next` | Move `tail` to the node we just attached (the new end). |
| `if l1: tail.next = l1` | List 2 is finished → attach all of what's left of list 1. |
| `elif l2: tail.next = l2` | Or the other way around. |
| `return dummy.next` | Skip the fake node; the real merged list starts after it. |

## Watch it run
`l1 = 1 → 2 → 4`, `l2 = 1 → 3 → 5`

| Round | Front of `l1` | Front of `l2` | Smaller (attach) | Merged chain so far |
|---|---|---|---|---|
| 1 | 1 | 1 | `l2`'s 1 (not smaller, so the `else` branch) | 1 |
| 2 | 1 | 3 | `l1`'s 1 | 1 → 1 |
| 3 | 2 | 3 | `l1`'s 2 | 1 → 1 → 2 |
| 4 | 4 | 3 | `l2`'s 3 | 1 → 1 → 2 → 3 |
| 5 | 4 | 5 | `l1`'s 4 | 1 → 1 → 2 → 3 → 4 |

`l1` is now empty, so the loop stops. Attach the rest of `l2` (just `5`): `1 → 1 → 2 → 3 → 4 → 5` ✅

## How fast is it?
- **Time: O(n + m).** Each node from both lists is looked at once.
- **Space: O(1).** We relink the existing nodes instead of creating new ones.
