# 104. Maximum Depth of Binary Tree
LeetCode: https://leetcode.com/problems/maximum-depth-of-binary-tree/ · Easy · Pattern: Tree recursion (DFS)

## Problem
Given the top of a binary tree (the `root`), return its **maximum depth**: the number of nodes on the longest path from the root down to the furthest leaf.

```
      1
     / \
    2   3
       /
      4

Output: 3       (the longest path is 1 → 3 → 4)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary tree** | A family tree where every **node** has at most two children: a `left` one and a `right` one. |
| **root** | The top node. |
| **leaf** | A node with no children. |
| **`None`** | "Nothing here". An empty spot where a child could be. |
| **recursion** | A function that **calls itself** on a smaller piece of the problem, like Russian nesting dolls: solving the big one means solving the smaller one inside it. |
| **base case** | The smallest piece, where the answer is obvious, so the function stops calling itself. |

## How to come up with it (the thinking)
**Step 1: ask the tiny question.** Forget the whole tree. Stand on **one node**. How deep is the tree below (and including) this node? It's **1** (this node) **plus** the depth of whichever child side is deeper.

**Step 2: but who knows the children's depths?** The same function does. Just call it on the left child and the right child. This is the "trust the recursion" step: assume the function works on the smaller trees.

**Step 3: when does it stop?** An empty spot (`None`) has depth **0**. That's the base case.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        return 1 + max(self.maxDepth(root.left), self.maxDepth(root.right))
```

## Line by line
| Line | What it does |
|---|---|
| `if not root:` | Is there nothing here (`None`)? |
| `return 0` | An empty spot has depth 0. This is the base case that stops the recursion. |
| `self.maxDepth(root.left)` | Ask the same function: "how deep is the left side?" |
| `self.maxDepth(root.right)` | ...and the right side. |
| `max(..., ...)` | Take the deeper of the two. |
| `1 + ...` | Add 1 for the current node itself. |

## Watch it run
Using the tree above (1 has children 2 and 3; 3 has left child 4). The calls finish from the bottom up:

| Call | Left depth | Right depth | Result `1 + max(...)` |
|---|---|---|---|
| `maxDepth(2)` (a leaf) | 0 (`None`) | 0 (`None`) | 1 + 0 = **1** |
| `maxDepth(4)` (a leaf) | 0 | 0 | 1 + 0 = **1** |
| `maxDepth(3)` | `maxDepth(4)` = 1 | 0 (`None`) | 1 + 1 = **2** |
| `maxDepth(1)` (root) | `maxDepth(2)` = 1 | `maxDepth(3)` = 2 | 1 + 2 = **3** |

Answer: **3** ✅

## How fast is it?
- **Time: O(n).** Each node is visited once.
- **Space: O(h).** The recursion stacks up as many calls as the tree is tall (h = height).
