# 49. Group Anagrams
LeetCode: https://leetcode.com/problems/group-anagrams/ · Medium · Pattern: Hash map (grouping by key)

## Problem
Given an array of lowercase strings `strs`, group the anagrams together. The groups and the order within a group can be returned in any order.

**Example**
```
Input: strs = ["act","pots","tops","cat","stop","hat"]
Output: [["hat"],["act","cat"],["stop","pots","tops"]]
```

## Solution
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        res = defaultdict(list)
        for s in strs:
            count = [0] * 26

            for c in s:
                count[ord(c) - ord("a")] += 1

            res[tuple(count)].append(s)

        return list(res.values())
```

Using `"act"` and `"cat"`:

1. Two words are anagrams exactly when their letter counts are identical, so the counts can act as a "fingerprint".
2. `count = [0] * 26` has one slot per letter. `ord(c) - ord("a")` maps `a→0, b→1, ... z→25`.
3. For `"act"`: slot 0 (a), slot 2 (c) and slot 19 (t) each become 1. `"cat"` produces the exact same list.
4. A list can't be a dictionary key, so `tuple(count)` turns it into one that can.
5. `res[fingerprint].append(s)` drops each word into its bucket. `defaultdict(list)` creates an empty list the first time a key appears.
6. `res.values()` is the list of buckets, which is the answer.

Sorting each word (`"".join(sorted(s))`) as the key also works, but costs O(L log L) per word. The count tuple is O(L). Overall: O(n·L) time and space, with n words of length up to L.
