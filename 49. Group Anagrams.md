# 49. Group Anagrams
LeetCode: https://leetcode.com/problems/group-anagrams/ · Medium · Pattern: Hash map (grouping by key)

## Problem
Given a list of lowercase words `strs`, put words that are **anagrams of each other** into the same group. Return the groups in any order.

```
Input:  ["act","pots","tops","cat","stop","hat"]
Output: [["hat"], ["act","cat"], ["stop","pots","tops"]]
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **anagram** | Same letters, rearranged ("act" and "cat"). |
| **fingerprint (key)** | Something identical for every word in a group. Here: how many times each letter appears. |
| **tuple** | A list that can't be changed, written `(1, 0, 2)`. Python only allows tuples (not normal lists) as dictionary keys. |
| **`ord(c)`** | Turns a letter into its number code: `ord("a")` is 97, `ord("b")` is 98. So `ord(c) - ord("a")` gives `a→0, b→1, ... z→25`. |
| **`defaultdict(list)`** | A dictionary that automatically creates an empty list the first time you use a new key. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Compare every word with every other word to see if they're anagrams. Very slow.

**Step 2: what do anagrams share?** Exactly the same letter counts. "act" and "cat" both have one a, one c, one t. So the letter counts work as a **fingerprint**.

**Step 3: the trick.** Compute a fingerprint for each word and use it as a **label on a box**. Words with the same fingerprint go into the same box. At the end, hand back all the boxes.

**Step 4: making the fingerprint.** Use 26 slots (one per letter), all starting at 0. For each letter, add 1 to its slot. Turn the slots into a tuple so it can be a dictionary key.

## Solution
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        res = defaultdict(list)
        for s in strs:
            count = [0] * 26

            for c in s:
                count[ord(c) - ord("a")] += 1

            res[tuple(count)].append(s)

        return list(res.values())
```

## Line by line
| Line | What it does |
|---|---|
| `res = defaultdict(list)` | The set of boxes. Each box is labelled by a fingerprint and holds a list of words. |
| `for s in strs:` | Take each word in turn. |
| `count = [0] * 26` | A fresh fingerprint: 26 slots (a to z), all 0. |
| `for c in s:` | Look at each letter of the word. |
| `count[ord(c) - ord("a")] += 1` | Find the letter's slot (a=0, b=1, ...) and add 1 to it. |
| `res[tuple(count)].append(s)` | Convert the fingerprint to a tuple, find the box with that label, and put the word inside. |
| `return list(res.values())` | Hand back all the boxes (just the word lists, not their labels). |

## Watch it run
`strs = ["act", "cat", "hat"]` (slots shown only for the letters that are non-zero)

| Word | Fingerprint (non-zero slots) | Box label | Boxes after |
|---|---|---|---|
| act | a=1, c=1, t=1 | K1 | `{K1: ["act"]}` |
| cat | a=1, c=1, t=1 | **K1** (same!) | `{K1: ["act","cat"]}` |
| hat | a=1, h=1, t=1 | K2 | `{K1: ["act","cat"], K2: ["hat"]}` |

Return the boxes → `[["act","cat"], ["hat"]]`.

## How fast is it?
- **Time: O(n · L).** n words, each with up to L letters to count.
- **Space: O(n · L).** All the words are stored in the boxes.
