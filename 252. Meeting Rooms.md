# 252. Meeting Rooms
LeetCode: https://leetcode.com/problems/meeting-rooms/ · Easy · Pattern: Sort intervals

## Problem
Given an array of meeting time intervals `[start, end)`, determine whether one person can attend all of the meetings (no two overlap).

**Example 1**
```
Input: intervals = [(0,30),(5,10),(15,20)]
Output: false      (0–30 overlaps with 5–10)
```

**Example 2**
```
Input: intervals = [(5,8),(9,15)]
Output: true
```

## Solution
```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

class Solution:
    def canAttendMeetings(self, intervals: List[Interval]) -> bool:
        intervals.sort(key=lambda i: i.start)

        for i in range(1, len(intervals)):
            i1 = intervals[i - 1]
            i2 = intervals[i]

            if i1.end > i2.start:
                return False
        return True
```

Using `[(0,30),(5,10),(15,20)]`:

1. After **sorting by start time**, any overlap must happen between meetings that are next to each other, so you only compare neighbours instead of every pair.
2. `key=lambda i: i.start` tells `sort` to order the meetings by their start value.
3. Compare each meeting with the one before it: `(0,30)` and `(5,10)`. The earlier meeting ends at 30, which is later than the next one's start (5): `30 > 5` → overlap → return `False`.
4. For `[(5,8),(9,15)]`: `8 > 9` is false, so no overlap. The loop ends → `True`.
5. A meeting that ends at the exact minute the next one starts is fine, which is why the check is `>` and not `>=`.

Sorting dominates: O(n log n) time, O(1) extra space.
