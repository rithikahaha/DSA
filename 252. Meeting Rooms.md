# 252. Meeting Rooms
LeetCode: https://leetcode.com/problems/meeting-rooms/ · Easy · Pattern: Sort intervals

## Problem
You have a list of meetings, each with a start time and an end time. Can **one person attend every meeting** (no two overlap)?

```
Input: [(0,30), (5,10), (15,20)]     Output: False    (0–30 overlaps 5–10)
Input: [(5,8), (9,15)]               Output: True
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **interval** | A stretch of time with a start and an end, e.g. a meeting from 5 to 10. |
| **overlap** | Two meetings share some time: one starts before the other has ended. |
| **`sort(key=...)`** | Sort a list using a rule you choose. |
| **`lambda i: i.start`** | A tiny throwaway function meaning "given a meeting `i`, use its start time". So `key=lambda i: i.start` sorts meetings by start time. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Compare every meeting with every other meeting for overlaps. Slow, and messy.

**Step 2: sort first.** Put the meetings in order of start time, like a diary. Now a clash can only happen between **neighbours**: if meeting 1 doesn't overlap meeting 2, and 2 doesn't overlap 3, then 1 can't overlap 3 either (they're further apart in time).

**Step 3: what counts as a clash?** The earlier meeting's **end** is later than the next meeting's **start**. (If it ends exactly when the next one starts, that's fine.)

## Solution
```python
"""
Definition of Interval:
class Interval(object):
    def __init__(self, start, end):
        self.start = start
        self.end = end
"""

class Solution:
    def canAttendMeetings(self, intervals: List[Interval]) -> bool:
        intervals.sort(key=lambda i: i.start)

        for i in range(1, len(intervals)):
            i1 = intervals[i - 1]
            i2 = intervals[i]

            if i1.end > i2.start:
                return False
        return True
```

## Line by line
| Line | What it does |
|---|---|
| `intervals.sort(key=lambda i: i.start)` | Put the meetings in order of start time. |
| `for i in range(1, len(intervals)):` | Go through the meetings from the 2nd one on (position 1), comparing each with the one before it. |
| `i1 = intervals[i - 1]` | The earlier meeting. |
| `i2 = intervals[i]` | The next meeting. |
| `if i1.end > i2.start:` | Does the earlier meeting end **after** the next one starts? |
| `return False` | Yes → a clash. One person can't attend both. |
| `return True` | No clash found anywhere. |

## Watch it run
`[(0,30), (5,10), (15,20)]` (already sorted by start)

| `i` | Earlier meeting `i1` | Next meeting `i2` | `i1.end > i2.start`? | Result |
|---|---|---|---|---|
| 1 | (0, 30) | (5, 10) | 30 > 5 → **Yes** | return **False** |

For `[(5,8), (9,15)]`:

| `i` | `i1` | `i2` | `i1.end > i2.start`? | Result |
|---|---|---|---|---|
| 1 | (5, 8) | (9, 15) | 8 > 9 → No | continue → loop ends → **True** |

## How fast is it?
- **Time: O(n log n).** Sorting is the expensive part; the check afterwards is one pass.
- **Space: O(1) extra.**
