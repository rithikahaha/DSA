# 271. Encode and Decode Strings
LeetCode: https://leetcode.com/problems/encode-and-decode-strings/ · Medium · Pattern: Length-prefix encoding

## Problem
Write two functions:
- `encode(strs)`: turn a **list of strings** into **one single string**.
- `decode(s)`: turn that single string back into the **exact original list**.

The strings can contain any characters at all.

```
["neet", "code"]  --encode-->  one string  --decode-->  ["neet", "code"]
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **encode / decode** | Encode = pack things into a form for sending. Decode = unpack them again. |
| **delimiter** | A separator character between items, like the comma in "a,b,c". |
| **slicing `s[a:b]`** | Take the piece of a string from position `a` up to (but **not** including) position `b`. `"hello"[1:3]` is `"el"`. |
| **`int("12")`** | Turns the text `"12"` into the number 12. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Join the words with a comma: `"neet,code"`. To decode, split on commas.

**Step 2: why it breaks.** What if a word itself contains a comma, like `"hi,there"`? Then decoding splits it wrongly. Any separator character could appear inside a word.

**Step 3: the trick.** Don't rely on a separator to find where a word ends. Write **how long the word is** in front of it: `4#neet`. When decoding, first read the length (4), then just **take exactly 4 characters**, whatever they are. The `#` only marks where the number ends, and since we always read the number first, a `#` inside a word can never confuse us.

## Solution
```python
class Solution:

    def encode(self, strs: List[str]) -> str:
        res = ""
        for s in strs:
            res += str(len(s)) + "#" + s
        return res

    def decode(self, s: str) -> List[str]:
        res, i = [], 0

        while i < len(s):
            j = i
            while s[j] != "#":
                j += 1
            length = int(s[i:j])
            res.append(s[j + 1 : j + 1 + length])
            i = j + 1 + length
        return res
```

## Line by line
**encode**

| Line | What it does |
|---|---|
| `res = ""` | Start with an empty string. |
| `for s in strs:` | Take each word. |
| `res += str(len(s)) + "#" + s` | Add: the word's length as text, then `#`, then the word. `"hi"` becomes `"2#hi"`. |

**decode**

| Line | What it does |
|---|---|
| `res, i = [], 0` | `res` is the list we'll rebuild; `i` is our position in the big string. |
| `while i < len(s):` | Keep going until we've read the whole string. |
| `j = i` | `j` will hunt for the `#`, starting where the length number starts. |
| `while s[j] != "#": j += 1` | Move `j` right until it lands on the `#`. |
| `length = int(s[i:j])` | The characters between `i` and `j` are the length number. Convert to a real number. |
| `res.append(s[j+1 : j+1+length])` | The word starts just after the `#` and is exactly `length` characters long. Slice it out and save it. |
| `i = j + 1 + length` | Jump `i` to the first character after the word, which is where the next length number begins. |

## Watch it run
`strs = ["hi", "yo"]` → encode gives `"2#hi2#yo"`. The characters by position:

| Position | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| Character | 2 | # | h | i | 2 | # | y | o |

**Decoding:**

| Round | `i` | `j` stops at (the `#`) | `s[i:j]` → `length` | Word = `s[j+1 : j+1+length]` | New `i` | `res` |
|---|---|---|---|---|---|---|
| 1 | 0 | 1 | `"2"` → 2 | `s[2:4]` = `"hi"` | 1+1+2 = 4 | `["hi"]` |
| 2 | 4 | 5 | `"2"` → 2 | `s[6:8]` = `"yo"` | 5+1+2 = 8 | `["hi","yo"]` |

`i = 8` equals the string length, so we stop. ✅

## How fast is it?
- **Time: O(total characters).** Each character is looked at a constant number of times.
- **Space: O(total characters).** For the encoded string / decoded list.
