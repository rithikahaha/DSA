# 15. 3Sum
LeetCode: https://leetcode.com/problems/3sum/ · Medium · Pattern: Sort + two pointers

## Problem
Given an integer array `nums`, return all unique triplets `[a, b, c]` (from three different indices) such that `a + b + c = 0`. The result must not contain duplicate triplets.

**Example**
```
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

## Solution
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        res = []
        nums.sort()

        for i, a in enumerate(nums):
            if i > 0 and a == nums[i - 1]:
                continue

            l, r = i + 1, len(nums) - 1
            while l < r:
                threeSum = a + nums[l] + nums[r]
                if threeSum > 0:
                    r -= 1
                elif threeSum < 0:
                    l += 1
                else:
                    res.append([a, nums[l], nums[r]])
                    l += 1
                    while nums[l] == nums[l - 1] and l < r:
                        l += 1
        return res
```

Using `nums = [-1,0,1,2,-1,-4]`:

1. **Sort:** `[-4,-1,-1,0,1,2]`. Sorted order lets two pointers steer toward zero, and puts duplicates next to each other.
2. Fix the first number `a`, then solve "find two numbers in the rest that add to `-a`" with `l` just after `i` and `r` at the end.
3. `a = -4`: no pair sums to 4. Move on.
4. `a = -1` (index 1): `l → -1`, `r → 2`. Sum = `-1 + -1 + 2 = 0` → save `[-1,-1,2]`. Move `l` right past any repeated value.
5. `l → 0`, `r → 2`: sum = 1 (too big) → `r -= 1`. `l → 0`, `r → 1`: sum = 0 → save `[-1,0,1]`.
6. `a = -1` (index 2): equals the previous `a`, so `continue`. Without this skip it would produce duplicate triplets.
7. Sum too big → shrink `r`. Sum too small → grow `l`.

Trying every triple is O(n³). Sorting costs O(n log n), and the two-pointer sweep is O(n) for each of the n choices of `a`, so the total is O(n²) time with O(1) extra space.
