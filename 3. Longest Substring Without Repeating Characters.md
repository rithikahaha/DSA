# 3. Longest Substring Without Repeating Characters
LeetCode: https://leetcode.com/problems/longest-substring-without-repeating-characters/ · Medium · Pattern: Sliding window

## Problem
Given a string `s`, return the length of the longest substring that contains no repeated characters.

**Example 1**
```
Input: s = "zxyzxyz"
Output: 3      ("zxy")
```

**Example 2**
```
Input: s = "xxxx"
Output: 1
```

## Solution
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        charSet = set()

        l = 0
        res = 0

        for r in range(len(s)):
            while s[r] in charSet:
                charSet.remove(s[l])
                l += 1
            charSet.add(s[r])
            res = max(res, r - l + 1)
        return res
```

Using `s = "zxyzxyz"`:

1. The window is `s[l..r]`, and `charSet` holds exactly the letters inside it. The window is always kept free of duplicates.
2. `r` moves right, one letter at a time. Letters `z`, `x`, `y` go in → window `"zxy"`, length 3, `res = 3`.
3. r=3 is `z`, which is already in the set. Shrink from the left: remove `s[0] = z`, `l = 1`. Now `z` isn't in the set anymore, so stop shrinking.
4. Add the new `z` → window `"xyz"` (length 3).
5. Continue the same way: each duplicate forces the left side forward until the window is valid again.
6. The longest window seen was 3 → return `3`.

`r - l + 1` is the current window length. `l` and `r` each move at most n times, so it's O(n) time. Space is O(min(n, alphabet size)).
