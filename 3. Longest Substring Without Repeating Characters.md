# 3. Longest Substring Without Repeating Characters
LeetCode: https://leetcode.com/problems/longest-substring-without-repeating-characters/ · Medium · Pattern: Sliding window

## Problem
Given a string `s`, find the **length of the longest stretch of characters (a substring) in which no letter repeats**.

```
Input: s = "zxyzxyz"     Output: 3      ("zxy")
Input: s = "xxxx"        Output: 1
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **substring** | A **continuous** piece of a string. "xyz" is a substring of "zxyzxyz"; "zyx" is not. |
| **sliding window** | A frame over part of the string, from position `l` (left edge) to `r` (right edge). We slide it along by moving the edges. |
| **set** | A bag that holds each item once and answers "is it in here?" instantly. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Check every possible substring for repeats. There are about n × n of them, and checking each takes more work. Way too slow.

**Step 2: the trick.** Keep a window that **never contains a repeat**. Move the right edge `r` forward one letter at a time, adding the new letter.

**Step 3: what if the new letter is already in the window?** The window is now invalid. Fix it by **moving the left edge `l` forward**, dropping letters from the window, until the repeated letter is gone.

**Step 4: measure.** After each step the window is valid, so its length (`r - l + 1`) is a candidate answer. Keep the largest.

## Solution
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        charSet = set()

        l = 0
        res = 0

        for r in range(len(s)):
            while s[r] in charSet:
                charSet.remove(s[l])
                l += 1
            charSet.add(s[r])
            res = max(res, r - l + 1)
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `charSet = set()` | The letters currently inside the window. |
| `l = 0` | Left edge of the window. |
| `res = 0` | Longest valid window found so far. |
| `for r in range(len(s)):` | Move the right edge one letter at a time. |
| `while s[r] in charSet:` | Is the new letter already in the window? (a repeat) |
| `charSet.remove(s[l])` | Drop the leftmost letter from the window's bag... |
| `l += 1` | ...and move the left edge right. Repeat until the repeat is gone. |
| `charSet.add(s[r])` | The window is clean now → add the new letter. |
| `res = max(res, r - l + 1)` | Window length is `r - l + 1`. Keep the largest. |

## Watch it run
`s = "zxyzxyz"`

| `r` | `s[r]` | Repeat in window? | Drop from left | Window | `res` |
|---|---|---|---|---|---|
| 0 | z | No | | `z` | 1 |
| 1 | x | No | | `zx` | 2 |
| 2 | y | No | | `zxy` | 3 |
| 3 | z | **Yes** (z) | drop z, `l = 1` | `xyz` | 3 |
| 4 | x | **Yes** (x) | drop x, `l = 2` | `yzx` | 3 |
| 5 | y | **Yes** (y) | drop y, `l = 3` | `zxy` | 3 |
| 6 | z | **Yes** (z) | drop z, `l = 4` | `xyz` | 3 |

Answer: **3** ✅

## How fast is it?
- **Time: O(n).** `r` moves n times and `l` moves at most n times in total.
- **Space: O(k).** The set holds at most one of each different letter (k = number of different letters).
