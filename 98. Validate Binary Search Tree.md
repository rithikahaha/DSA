# 98. Validate Binary Search Tree
LeetCode: https://leetcode.com/problems/validate-binary-search-tree/ · Medium · Pattern: Tree recursion with bounds

## Problem
Return `True` if a binary tree is a valid **binary search tree**: for every node, **all** values in its left subtree are smaller and **all** values in its right subtree are bigger.

```
Tree A:   2            → True
         / \
        1   3

Tree B:   5            → False
         / \
        1   6          (3 is in the right side of 5,
           / \          so it must be bigger than 5)
          3   7
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary search tree (BST)** | For every node: everything to its **left is smaller**, everything to its **right is bigger**. |
| **range `(left, right)`** | The allowed values for a node: strictly bigger than `left` and strictly smaller than `right`. |
| **`float("inf")`** | Infinity: a number bigger than any real number. `-inf` is smaller than any. Used for "no limit". |
| **inner function** | A function defined inside another function (`valid` inside `isValidBST`). |
| **recursion** | A function that calls itself on smaller pieces. |

## How to come up with it (the thinking)
**Step 1: the tempting (wrong) idea.** "For each node, check that its left child is smaller and its right child is bigger." That misses a lot! In Tree B, `3` is smaller than its parent `6`, and `7` is bigger than `6`, so locally it all looks fine. But `3` sits in the **right side of 5**, so it must be bigger than **5**. Comparing with the parent alone can't catch that.

**Step 2: what's really required.** A node must obey **every ancestor above it**, not just its parent. So each node carries an **allowed range** inherited from above.

**Step 3: how the range shrinks.** The root can be anything: range `(-inf, +inf)`. When we go **left** from a node with value `v`, everything there must be **less than `v`**, so the upper limit becomes `v`. When we go **right**, everything must be **more than `v`**, so the lower limit becomes `v`.

**Step 4: check each node.** If a node is outside its range, the tree is invalid. An empty spot is fine.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:

        def valid(node, left, right):
            if not node:
                return True

            if not (node.val < right and node.val > left):
                return False

            return (valid(node.left, left, node.val) and
                    valid(node.right, node.val, right))
        return valid(root, float("-inf"), float("inf"))
```

## Line by line
| Line | What it does |
|---|---|
| `def valid(node, left, right):` | Checks one node, given its allowed range (`left` = lower limit, `right` = upper limit). |
| `if not node: return True` | An empty spot is always fine (base case). |
| `if not (node.val < right and node.val > left):` | Is the node's value **outside** its allowed range? |
| `return False` | Then the tree is not a BST. |
| `valid(node.left, left, node.val)` | Check the left child: same lower limit, but now it must be **less than this node**. |
| `valid(node.right, node.val, right)` | Check the right child: it must be **more than this node**, same upper limit. |
| `and` | Both sides must be valid. |
| `return valid(root, float("-inf"), float("inf"))` | Start at the root with no limits. |

## Watch it run
Tree B: `5 (1, 6 (3, 7))`

| Node | Allowed range | Value in range? | Passes range to children |
|---|---|---|---|
| 5 (root) | (-inf, inf) | Yes | left gets (-inf, 5); right gets (5, inf) |
| 1 | (-inf, 5) | Yes | (its children are empty → True) |
| 6 | (5, inf) | Yes | left gets (5, 6); right gets (6, inf) |
| 3 | (5, 6) | **No**, 3 is not bigger than 5 | return **False** |

Answer: **False** ✅ (We caught it because `3` inherited "must be bigger than 5" from the root, two levels up.)

## How fast is it?
- **Time: O(n).** Each node is checked once.
- **Space: O(h).** Recursion depth = tree height.
