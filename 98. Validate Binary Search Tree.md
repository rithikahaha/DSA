# 98. Validate Binary Search Tree
LeetCode: https://leetcode.com/problems/validate-binary-search-tree/ · Medium · Pattern: Tree recursion with bounds

## Problem
Given the root of a binary tree, return `true` if it's a valid binary search tree: for every node, all values in its left subtree are strictly smaller and all values in its right subtree are strictly larger.

**Example 1**
```
Input: root = [2,1,3]
Output: true
```

**Example 2**
```
Input: root = [5,1,4,null,null,3,6]
Output: false      (4 is in the right subtree of 5 but is smaller than 5)
```

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:

        def valid(node, left, right):
            if not node:
                return True

            if not (node.val < right and node.val > left):
                return False

            return (valid(node.left, left, node.val) and
                    valid(node.right, node.val, right))
        return valid(root, float("-inf"), float("inf"))
```

Using `root = [5,1,4,null,null,3,6]`:

1. The trap: checking only `left.val < node.val < right.val` misses cases like the `4` above. `4 > 1` looks fine locally, but `4` sits in `5`'s right subtree, so it must be greater than 5.
2. So every node carries a **valid range** `(left, right)` passed down from all its ancestors. The root starts with `(-inf, +inf)`.
3. Node `5` is inside `(-inf, +inf)`. ✔ Its left child gets `(-inf, 5)` and its right child gets `(5, +inf)`.
4. Node `1` is inside `(-inf, 5)`. ✔
5. Node `4` needs to be inside `(5, +inf)`, but `4 > 5` is false → return `False`.
6. An empty node is trivially valid (base case → `True`). Both subtrees must be valid, hence the `and`.

Each node is checked once: O(n) time, O(h) space.
