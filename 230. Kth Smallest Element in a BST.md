# 230. Kth Smallest Element in a BST
LeetCode: https://leetcode.com/problems/kth-smallest-element-in-a-bst/ · Medium · Pattern: In-order traversal (stack)

## Problem
Given a binary search tree and a number `k`, return the **`k`-th smallest value** (counting from 1).

```
        4
       / \
      3   5
     /
    2
   /
  1

k = 4   →   4      (sorted values: 1, 2, 3, 4, 5)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary search tree (BST)** | Everything to the **left** of a node is smaller; everything to the **right** is bigger. |
| **in-order traversal** | Visit the **left subtree first, then the node itself, then the right subtree**. On a BST this visits values in **sorted order**. |
| **stack** | A pile of plates: add on top, remove from the top ("last in, first out"). |
| **push / pop** | Put on top of the pile / take off the top. |

## How to come up with it (the thinking)
**Step 1: use the BST rule.** The smallest value is the **leftmost** node (keep going left). After it come its parent, then the parent's right subtree, and so on. That is exactly an in-order walk, and it gives the numbers **already sorted**.

**Step 2: so the answer is just the k-th node visited** in that walk. Count as you go and stop at `k`.

**Step 3: how to walk in-order without recursion.** Use a stack to remember "the nodes I still need to come back to":
1. Go left as far as possible, **pushing** every node on the way (they're waiting for their turn).
2. **Pop** one. That's the next smallest. Count it.
3. Then move to its **right** child and repeat step 1.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        n = 0
        stack = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left

            cur = stack.pop()
            n += 1
            if n == k:
                return cur.val
            cur = cur.right
```

## Line by line
| Line | What it does |
|---|---|
| `n = 0` | How many nodes we've visited so far. |
| `stack = []` | The pile of nodes waiting for their turn. |
| `cur = root` | `cur` is the node we're standing on. |
| `while cur or stack:` | Continue while there's a node to move to, or nodes waiting on the pile. |
| `while cur: stack.append(cur); cur = cur.left` | Go as far left as possible, pushing each node on the way. |
| `cur = stack.pop()` | Take the top node: the smallest one not yet visited. |
| `n += 1` | Count it. |
| `if n == k: return cur.val` | It's the k-th smallest. Done! |
| `cur = cur.right` | Otherwise move to its right subtree, and repeat. |

## Watch it run
Tree above (`4` has left `3` and right `5`; `3` has left `2`; `2` has left `1`), `k = 4`.

| Step | What happens | `stack` (top on the right) | `n` |
|---|---|---|---|
| 1 | Go left from 4: push 4, 3, 2, 1. Then `cur = None`. | `[4, 3, 2, 1]` | 0 |
| 2 | Pop **1** (smallest). Count it. Its right child is `None`. | `[4, 3, 2]` | 1 |
| 3 | Pop **2**. Count it. Right child `None`. | `[4, 3]` | 2 |
| 4 | Pop **3**. Count it. Right child `None`. | `[4]` | 3 |
| 5 | Pop **4**. Count it → `n == 4 == k`. | `[]` | 4 → return **4** |

Answer: **4** ✅

## How fast is it?
- **Time: O(h + k).** Go down the left side, then visit `k` nodes (h = tree height).
- **Space: O(h).** The stack holds at most one path.
