# 230. Kth Smallest Element in a BST
LeetCode: https://leetcode.com/problems/kth-smallest-element-in-a-bst/ · Medium · Pattern: In-order traversal (stack)

## Problem
Given the root of a binary search tree and an integer `k`, return the `k`-th smallest value (1-indexed) among all node values.

**Example**
```
Input: root = [4,3,5,2,null,null,null,1], k = 4
Output: 4      (sorted values are 1,2,3,4,5)
```

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        n = 0
        stack = []
        cur = root

        while cur or stack:
            while cur:
                stack.append(cur)
                cur = cur.left

            cur = stack.pop()
            n += 1
            if n == k:
                return cur.val
            cur = cur.right
```

Using the tree `2` with children `1` (left) and `3` (right), `k = 2`:

1. Visiting a BST in **in-order** (left subtree → node → right subtree) yields the values in sorted order. So the `k`-th node visited is the `k`-th smallest.
2. The stack replaces recursion. Go as far left as possible, pushing each node: stack `[2, 1]`, and `cur = None`.
3. Pop `1`. It's the smallest, so `n = 1` (not `k` yet). Move to its right child (`None`).
4. `cur` is `None`, so skip the inner loop and pop `2`. `n = 2 == k` → return `2`.
5. If `n < k`, go to the popped node's right child and repeat: push its whole left spine, then pop again.

You stop as soon as you've counted `k` nodes: O(h + k) time and O(h) space.
