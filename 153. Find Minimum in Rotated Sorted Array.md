# 153. Find Minimum in Rotated Sorted Array
LeetCode: https://leetcode.com/problems/find-minimum-in-rotated-sorted-array/ · Medium · Pattern: Binary search

## Problem
A sorted array of distinct values was rotated between 1 and n times (e.g. `[1,2,3,4,5]` → `[3,4,5,1,2]`). Return the minimum element in O(log n).

**Example 1**
```
Input: nums = [3,4,5,6,1,2]
Output: 1
```

**Example 2**
```
Input: nums = [4,5,0,1,2,3]
Output: 0
```

## Solution
```python
class Solution:
    def findMin(self, nums: List[int]) -> int:
        res = nums[0]
        l, r = 0, len(nums) - 1

        while l <= r:
            if nums[l] < nums[r]:
                res = min(res, nums[l])
                break

            m = (l + r) // 2
            res = min(res, nums[m])
            if nums[m] >= nums[l]:
                l = m + 1
            else:
                r = m - 1
        return res
```

Using `nums = [3,4,5,6,1,2]`:

1. A rotated array is two sorted runs: a big-values run `3,4,5,6` followed by a small-values run `1,2`. The minimum is the first element of the small run.
2. `res` tracks the smallest value seen. Start with `nums[0] = 3`.
3. `nums[l] < nums[r]` would mean this slice is untouched by the rotation (already sorted), so the answer is `nums[l]`. Here `3 < 2` is false, so continue.
4. `m = 2`, `nums[2] = 5`; `res = min(3, 5) = 3`. `nums[m] >= nums[l]` means `m` sits in the big-values run, so the minimum must be to the right → `l = 3`.
5. Slice `[6,1,2]`: `6 < 2` false. `m = 4`, `nums[4] = 1`, `res = 1`. `1 >= 6` is false, so `m` is in the small run and the minimum is at `m` or further left → `r = 3`.
6. Slice `[6]`: `nums[l] < nums[r]` is false (equal). `m = 3`, `res = min(1, 6) = 1`. `6 >= 6` → `l = 4`. Now `l > r` → return `1`.

Comparing the middle with the left end tells you which run you're in, so you can discard half each time: O(log n) time, O(1) space.
