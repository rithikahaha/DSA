# 226. Invert Binary Tree
LeetCode: https://leetcode.com/problems/invert-binary-tree/ · Easy · Pattern: Tree recursion (DFS)

## Problem
**Flip a binary tree** left-to-right like a mirror: at every node, swap its left and right children. Return the root.

```
Before:       1             After:        1
            /   \                       /   \
           2     3                     3     2
          / \   / \                   / \   / \
         4   5 6   7                 7   6 5   4
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary tree** | Every **node** has at most two children: `left` and `right`. |
| **root** | The top node. |
| **`None`** | "Nothing here": an empty spot. |
| **recursion** | A function that calls **itself** on a smaller piece. |
| **base case** | The obvious smallest case (an empty spot) where the function just stops. |

## How to come up with it (the thinking)
**Step 1: look at one node.** To mirror a tree, what must happen at *this* node? Swap its left and right children. That's it.

**Step 2: what about the rest of the tree?** After swapping, each child is itself the top of a smaller tree that also needs mirroring. The same function can do it. Just call it on the (new) left child and the (new) right child.

**Step 3: when does it stop?** When we reach an empty spot (`None`), there's nothing to swap, so we return.

**Step 4: swapping needs a spare box.** To swap two things you need a temporary variable: put A aside, move B into A's place, then put A into B's place.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None

        tmp = root.left
        root.left = root.right
        root.right = tmp

        self.invertTree(root.left)
        self.invertTree(root.right)
        return root
```

## Line by line
| Line | What it does |
|---|---|
| `if not root: return None` | Empty spot → nothing to do (base case). |
| `tmp = root.left` | Put the left child aside in a spare variable. |
| `root.left = root.right` | Move the right child into the left slot. |
| `root.right = tmp` | Put the saved old-left child into the right slot. Swap done. |
| `self.invertTree(root.left)` | Now mirror everything below the left child. |
| `self.invertTree(root.right)` | ...and below the right child. |
| `return root` | Hand back the top of the mirrored tree. |

## Watch it run
Tree: `1 (2 (4, 5), 3 (6, 7))`

| Call | What it does at this node | Children after the swap |
|---|---|---|
| `invert(1)` | swap 2 and 3 | left = 3, right = 2 |
| `invert(3)` (new left) | swap 6 and 7 | left = 7, right = 6 |
| `invert(7)`, `invert(6)` | leaves: swap `None` and `None`, nothing changes | |
| `invert(2)` (new right) | swap 4 and 5 | left = 5, right = 4 |
| `invert(5)`, `invert(4)` | leaves: nothing changes | |

Result: `1 (3 (7, 6), 2 (5, 4))` ✅

## How fast is it?
- **Time: O(n).** Every node is visited once.
- **Space: O(h).** The recursion goes as deep as the tree is tall (h = height).
