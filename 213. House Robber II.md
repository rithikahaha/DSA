# 213. House Robber II
LeetCode: https://leetcode.com/problems/house-robber-ii/ · Medium · Pattern: Dynamic programming (run it twice)

## Problem
Same as House Robber, except the houses are in a **circle**: the first and last houses are neighbours. You **can't rob two adjacent houses**. What's the most you can rob?

```
Input: nums = [3, 4, 3]           Output: 4     (the two 3s are neighbours in a circle, so rob only the 4)
Input: nums = [2, 9, 8, 3, 6]     Output: 15    (9 + 6)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **circle / circular** | The last house wraps around and touches the first. |
| **slice `nums[1:]`** | The list **without the first item**. |
| **slice `nums[:-1]`** | The list **without the last item**. |
| **`helper`** | The ordinary House Robber (problem 198) solver for a straight line of houses. |

## How to come up with it (the thinking)
**Step 1: what changed?** Only one rule: house 0 and the last house can't **both** be robbed.

**Step 2: turn one hard problem into two easy ones.** Either we don't rob the first house, or we don't rob the last house (at least one of them is left out in the best plan). So solve two separate straight-street problems and take the better result:
- **Option A:** skip the first house → solve `nums[1:]`.
- **Option B:** skip the last house → solve `nums[:-1]`.

**Step 3: handle one house.** With a single house, both slices are empty (worth 0), but robbing that one house is allowed. Including `nums[0]` in the final `max` covers this.

## Solution
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        return max(nums[0], self.helper(nums[1:]), self.helper(nums[:-1]))

    def helper(self, nums):
        rob1, rob2 = 0, 0

        for n in nums:
            newRob = max(rob1 + n, rob2)
            rob1 = rob2
            rob2 = newRob
        return rob2
```

## Line by line
| Line | What it does |
|---|---|
| `self.helper(nums[1:])` | Best for the street with the **first** house removed. |
| `self.helper(nums[:-1])` | Best for the street with the **last** house removed. |
| `max(nums[0], ..., ...)` | Take the best of both options (and `nums[0]` for the single-house case). |
| `rob1, rob2 = 0, 0` | (Inside `helper`) `rob2` = best up to the previous house, `rob1` = best up to two back. |
| `newRob = max(rob1 + n, rob2)` | For this house: rob it (`rob1 + n`) or skip it (`rob2`). |
| `rob1 = rob2; rob2 = newRob` | Slide forward. |
| `return rob2` | Best for the whole straight street. |

## Watch it run
`nums = [2, 9, 8, 3, 6]`

**Option A**: skip the first house → `helper([9, 8, 3, 6])`

| House | `n` | `rob1 + n` | `rob2` | `newRob` |
|---|---|---|---|---|
| 9 | 9 | 0 + 9 = 9 | 0 | 9 |
| 8 | 8 | 0 + 8 = 8 | 9 | 9 |
| 3 | 3 | 9 + 3 = 12 | 9 | 12 |
| 6 | 6 | 9 + 6 = 15 | 12 | **15** |

**Option B**: skip the last house → `helper([2, 9, 8, 3])`

| House | `n` | `rob1 + n` | `rob2` | `newRob` |
|---|---|---|---|---|
| 2 | 2 | 0 + 2 = 2 | 0 | 2 |
| 9 | 9 | 0 + 9 = 9 | 2 | 9 |
| 8 | 8 | 2 + 8 = 10 | 9 | 10 |
| 3 | 3 | 9 + 3 = 12 | 10 | **12** |

`max(2, 15, 12)` = **15** ✅

## How fast is it?
- **Time: O(n).** Two passes.
- **Space: O(n).** The slices make copies of the list.
