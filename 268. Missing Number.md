# 268. Missing Number
LeetCode: https://leetcode.com/problems/missing-number/ · Easy · Pattern: Math / cancelling sums

## Problem
`nums` holds `n` **different** numbers taken from the range `0` to `n`. Exactly one number in that range is **missing**. Find it.

```
Input: nums = [3, 0, 1]     Output: 2      (the range is 0..3, and 2 is missing)
Input: nums = [0, 2]        Output: 1
Input: nums = [1, 2, 3]     Output: 0
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **range `0..n`** | Every whole number from 0 up to `n`. For `n = 3`: 0, 1, 2, 3. |
| **sum** | All the numbers added together. |
| **index** | A position in the list, starting at 0. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Put all the numbers in a set and check each of 0, 1, ..., n to see which one is absent. That works, but uses extra memory.

**Step 2: think about totals.** If nothing were missing, the numbers would be `0 + 1 + 2 + ... + n`. The list has everything except one number, so:
> **missing = (sum of 0..n) − (sum of the list)**

For `[3, 0, 1]`: `0+1+2+3 = 6` and the list adds to `4`, so the missing number is `6 − 4 = 2`.

**Step 3: do it in one loop.** Instead of computing two sums separately, let one running total do both jobs. Start with `res = n` (the one number the index loop won't reach), and for each position `i`, **add `i` and subtract `nums[i]`**. All the indices `0..n−1` plus `n` add up to `0 + ... + n`, and subtracting every list value removes all the numbers that are present.

## Solution
```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        res = len(nums)

        for i in range(len(nums)):
            res += (i - nums[i])

        return res
```

## Line by line
| Line | What it does |
|---|---|
| `res = len(nums)` | Start with `n` (the list has `n` items, and the range goes up to `n`). |
| `for i in range(len(nums)):` | Go through each position `i` = 0, 1, ..., n−1. |
| `res += (i - nums[i])` | Add the position number, subtract the value stored there. |
| `return res` | What's left over is the number nobody subtracted: the missing one. |

## Watch it run
`nums = [3, 0, 1]`, so `n = 3`.

| `i` | `nums[i]` | `i − nums[i]` | `res` after |
|---|---|---|---|
| start | | | 3 |
| 0 | 3 | 0 − 3 = −3 | 0 |
| 1 | 0 | 1 − 0 = 1 | 1 |
| 2 | 1 | 2 − 1 = 1 | 2 |

Answer: **2** ✅

(Check: `res = 3 + (0+1+2) − (3+0+1) = 6 − 4 = 2`.)

## How fast is it?
- **Time: O(n).** One pass.
- **Space: O(1).** One variable.
