# 268. Missing Number
LeetCode: https://leetcode.com/problems/missing-number/ · Easy · Pattern: Math / cancelling sums

## Problem
Given an array `nums` containing `n` distinct numbers from the range `[0, n]`, return the one number in that range that is missing.

**Example**
```
Input: nums = [1,2,3]
Output: 0

Input: nums = [0,2]
Output: 1
```

## Solution
```python
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        res = len(nums)

        for i in range(len(nums)):
            res += (i - nums[i])

        return res
```

Using `nums = [0,2]` (`n = 2`, so the full range is 0, 1, 2):

1. The full set is `0..n`, and `nums` has all of it except one number. If you take the sum of `0..n` and subtract the sum of `nums`, what's left is the missing number.
2. The code does this in one loop without computing two sums. Start with `res = n` (the one index that has no partner in the loop).
3. For each index `i`, add `i` and subtract `nums[i]`. The starting `n` plus the indices `0..n-1` add up to `0 + 1 + ... + n` (the full range), and subtracting every array value removes each number that is present. Only the missing one is left over.
4. `res = 2`. i=0: `+ (0 - 0)` → 2. i=1: `+ (1 - 2)` → 1.
5. Return `1`.

A set or sorting approach also works, but this is one pass with no extra memory: O(n) time, O(1) space.
