# 371. Sum of Two Integers
LeetCode: https://leetcode.com/problems/sum-of-two-integers/ · Medium · Pattern: Bit manipulation

## Problem
Given two integers `a` and `b`, return their sum **without using the `+` or `-` operators**.

**Example**
```
Input: a = 1, b = 1
Output: 2
```

## Solution
```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        MASK = 0xffffffff
        MAX_INT = 0x7fffffff

        while b:
            carry = (a & b) & MASK
            a = (a ^ b) & MASK
            b = (carry << 1) & MASK

        return a if a <= MAX_INT else ~(a ^ MASK)
```

Using `a = 1`, `b = 1`:

1. Binary addition has two parts. `a ^ b` (XOR) is the sum **ignoring carries**: `1 + 1 = 0` in one column. `(a & b) << 1` is the **carries**: a carry happens where both bits are 1, and it moves one column left.
2. Add the two parts together, which is the same problem again. Repeat until there's no carry left (`b == 0`).
3. `a = 1`, `b = 1`: `a ^ b = 0`, carry = `(1 & 1) << 1 = 2`. Now `a = 0`, `b = 2`.
4. `a ^ b = 2`, carry = `(0 & 2) << 1 = 0`. Now `a = 2`, `b = 0`. The loop ends → `2`.
5. **Why the mask?** Python integers have no size limit, so a negative number's bits would extend forever. `& 0xffffffff` keeps everything to 32 bits like a normal int.
6. **The last line** converts back: if `a <= 0x7fffffff`, bit 31 is 0 and it's a positive number. Otherwise the 32-bit pattern represents a negative number, and `~(a ^ MASK)` restores the Python negative value.

At most 32 iterations: O(1) time and space.
