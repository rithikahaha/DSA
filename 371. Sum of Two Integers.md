# 371. Sum of Two Integers
LeetCode: https://leetcode.com/problems/sum-of-two-integers/ · Medium · Pattern: Bit manipulation

## Problem
Add two integers `a` and `b` **without using `+` or `-`**.

```
Input: a = 1, b = 1     Output: 2
Input: a = 5, b = 3     Output: 8
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **binary** | Numbers written with only 0 and 1. 5 = `101`, 3 = `011`. |
| **XOR `a ^ b`** | Compare bit by bit: the result bit is 1 if the two bits are **different**, 0 if they're the same. |
| **AND `a & b`** | The result bit is 1 only if **both** bits are 1. |
| **left shift `x << 1`** | Slide all bits one place left (this doubles the number). |
| **carry** | In school addition, when a column adds to more than the digit can hold, you "carry" the extra to the next column on the left. |
| **mask `0xffffffff`** | 32 ones in binary. `x & mask` keeps only the lowest 32 bits. |

## How to come up with it (the thinking)
**Step 1: think about how you add on paper.** You add each column, and if it overflows you carry. Binary works the same way, just with 0 and 1. In one column: `0+0=0`, `0+1=1`, `1+0=1`, and `1+1=0 carry 1`.

**Step 2: split addition into two parts.**
- **Sum without carrying:** the column result is 1 only when the bits **differ** → that's `a ^ b`.
- **The carries:** a carry appears only when **both** bits are 1 → `a & b`, and it goes into the **next column to the left** → `(a & b) << 1`.

**Step 3: add the two parts together.** But that's the same problem again (adding two numbers)! So repeat: treat "sum without carry" as the new `a` and "carries" as the new `b`. Keep going until there are **no carries left** (`b == 0`). Then `a` is the answer.

**Step 4: the mask.** Python integers never overflow and negative numbers have endless leading 1s in binary, which would make the loop run forever. So we cut everything to **32 bits** with the mask. The last line converts a 32-bit "negative" pattern back into a proper negative Python number.

## Solution
```python
class Solution:
    def getSum(self, a: int, b: int) -> int:
        MASK = 0xffffffff
        MAX_INT = 0x7fffffff

        while b:
            carry = (a & b) & MASK
            a = (a ^ b) & MASK
            b = (carry << 1) & MASK

        return a if a <= MAX_INT else ~(a ^ MASK)
```

## Line by line
| Line | What it does |
|---|---|
| `MASK = 0xffffffff` | 32 ones: used to keep numbers within 32 bits. |
| `MAX_INT = 0x7fffffff` | The biggest positive 32-bit number (`0` then 31 ones). |
| `while b:` | While there's still a carry to add in. |
| `carry = (a & b) & MASK` | The columns where both bits are 1 (these produce carries). |
| `a = (a ^ b) & MASK` | The sum **without** carries. |
| `b = (carry << 1) & MASK` | Move the carries one column left. They become the new number to add. |
| `return a if a <= MAX_INT else ~(a ^ MASK)` | If the top bit isn't set, `a` is a normal positive number. Otherwise it represents a negative number, so convert it back. |

## Watch it run
`a = 5` (`101`), `b = 3` (`011`)

| Round | `a` (binary) | `b` (binary) | `a ^ b` (sum, no carry) | `(a & b) << 1` (carries) | New `a`, new `b` |
|---|---|---|---|---|---|
| 1 | `0101` | `0011` | `0110` (6) | `0010` (2) | 6, 2 |
| 2 | `0110` | `0010` | `0100` (4) | `0100` (4) | 4, 4 |
| 3 | `0100` | `0100` | `0000` (0) | `1000` (8) | 0, 8 |
| 4 | `0000` | `1000` | `1000` (8) | `0000` (0) | 8, 0 |

`b` is 0, so we're done. Answer: **8** ✅ (5 + 3 = 8)

## How fast is it?
- **Time: O(1).** At most 32 rounds.
- **Space: O(1).**
