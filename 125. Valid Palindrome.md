# 125. Valid Palindrome
LeetCode: https://leetcode.com/problems/valid-palindrome/ · Easy · Pattern: String cleaning / two pointers

## Problem
A phrase is a palindrome if, after lowercasing it and removing everything that isn't a letter or digit, it reads the same forwards and backwards. Given a string `s`, return `true` if it's a palindrome.

**Example 1**
```
Input: s = "Was it a car or a cat I saw?"
Output: true      ("wasitacaroracatisaw" reads the same both ways)
```

**Example 2**
```
Input: s = "tab a cat"
Output: false     ("tabacat" reversed is "tacabat")
```

## Solution
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        newStr = ""

        for c in s:
            if c.isalnum():
                newStr += c.lower()
        return newStr == newStr[::-1]
```

Using `s = "tab a cat"`:

1. Go through each character. `c.isalnum()` is true only for letters and digits, so spaces and punctuation are dropped.
2. `c.lower()` makes the comparison case-insensitive.
3. After cleaning: `newStr = "tabacat"`.
4. `newStr[::-1]` is the string reversed: `"tacabat"`.
5. Compare them: `"tabacat" != "tacabat"` → `False`.

This is O(n) time but uses O(n) extra space for the cleaned copy. A two-pointer version keeps `l` at the start and `r` at the end, skips non-alphanumeric characters, compares the two, and moves inward, which needs only O(1) space.
