# 125. Valid Palindrome
LeetCode: https://leetcode.com/problems/valid-palindrome/ · Easy · Pattern: String cleaning / two pointers

## Problem
A phrase is a **palindrome** if it reads the same forwards and backwards once you **ignore spaces, punctuation and capital letters**. Return `True` if it is one.

```
"Was it a car or a cat I saw?"  → True    ("wasitacaroracatisaw" is the same both ways)
"tab a cat"                     → False   ("tabacat" backwards is "tacabat")
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **palindrome** | Reads the same in both directions: "level", "racecar". |
| **`c.isalnum()`** | True if the character `c` is a **letter or a digit**. False for spaces, commas, `?` and so on. |
| **`c.lower()`** | Turns a letter into lowercase, so "A" and "a" count as equal. |
| **`s[::-1]`** | A copy of the string `s` **reversed**. `"abc"[::-1]` is `"cba"`. |

## How to come up with it (the thinking)
**Step 1: two separate jobs.** (a) Get rid of the junk (spaces, punctuation, capitals). (b) Check whether what's left reads the same backwards.

**Step 2: job (a).** Build a new, clean string. Go through the original character by character, keep only letters/digits, and lowercase them.

**Step 3: job (b).** Python can reverse a string in one go. If the clean string equals its own reverse, it's a palindrome.

## Solution
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        newStr = ""

        for c in s:
            if c.isalnum():
                newStr += c.lower()
        return newStr == newStr[::-1]
```

## Line by line
| Line | What it does |
|---|---|
| `newStr = ""` | Start with an empty clean string. |
| `for c in s:` | Look at each character of the original. |
| `if c.isalnum():` | Is it a letter or digit? Spaces and punctuation fail this test and are skipped. |
| `newStr += c.lower()` | Add its lowercase version to the end of the clean string. |
| `return newStr == newStr[::-1]` | Compare the clean string with its reverse. Same → `True`. |

## Watch it run
`s = "Ab,a"`

| `c` | `isalnum()`? | `newStr` after |
|---|---|---|
| A | Yes | `"a"` |
| b | Yes | `"ab"` |
| , | **No**, skipped | `"ab"` |
| a | Yes | `"aba"` |

`newStr = "aba"`, and `newStr[::-1] = "aba"`. Equal → `True` ✅

(For `"tab a cat"` the clean string is `"tabacat"`, the reverse is `"tacabat"`. They differ → `False`.)

## How fast is it?
- **Time: O(n).** One pass to clean, one to reverse and compare.
- **Space: O(n).** We built a second, cleaned copy of the string. (A "two pointers" version, comparing the first and last letters and moving inward, avoids the copy and uses O(1) space.)
