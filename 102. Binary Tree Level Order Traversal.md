# 102. Binary Tree Level Order Traversal
LeetCode: https://leetcode.com/problems/binary-tree-level-order-traversal/ · Medium · Pattern: BFS (queue)

## Problem
Return the values of a binary tree **level by level**, top to bottom, left to right, as a list of lists.

```
      3
     / \
    9   20
       /  \
      15   7

Output: [[3], [9, 20], [15, 7]]
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **level** | All nodes at the same distance from the top. The root is level 1, its children level 2, and so on. |
| **queue** | A line at a shop. People join at the **back** and are served from the **front**: "first in, first out". |
| **`deque`** | Python's efficient queue. `q.append(x)` joins the back; `q.popleft()` serves the front. |
| **BFS (breadth-first search)** | Exploring a tree **level by level**, visiting all nodes at one level before going deeper. |
| **`None`** | An empty spot (a missing child). |

## How to come up with it (the thinking)
**Step 1: why a queue?** We want to finish a whole level before starting the next. A queue does that naturally: when we serve a node, we put its children at the **back** of the line, so they're served after everyone already in line (the rest of the current level).

**Step 2: the tricky part is knowing where a level ends.** Trick: at the start of each round, **count how many people are in the queue right now** (`qLen`). Those are exactly the nodes of the current level. Serve exactly that many, and everyone who joins meanwhile belongs to the next level.

**Step 3: record.** For each level, collect its values into a small list, then add that list to the answer.

## Solution
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def levelOrder(self, root: Optional[TreeNode]) -> List[List[int]]:
        res = []

        q = collections.deque()
        q.append(root)

        while q:
            qLen = len(q)
            level = []
            for i in range(qLen):
                node = q.popleft()
                if node:
                    level.append(node.val)
                    q.append(node.left)
                    q.append(node.right)
            if level:
                res.append(level)
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `res = []` | The final list of levels. |
| `q = collections.deque(); q.append(root)` | Make the queue and put the root in line. |
| `while q:` | Keep going while anyone is still in line. |
| `qLen = len(q)` | How many are in line right now = the size of this level. |
| `level = []` | A fresh list for this level's values. |
| `for i in range(qLen):` | Serve exactly that many people. |
| `node = q.popleft()` | Take the person at the front. |
| `if node:` | Skip empty spots (`None`). |
| `level.append(node.val)` | Record this node's value. |
| `q.append(node.left); q.append(node.right)` | Its children join the back of the line (for the next level). |
| `if level: res.append(level)` | Save the level (ignore a level that was all empty spots). |

## Watch it run
Tree: `3 (9, 20 (15, 7))`. Empty spots are written `∅`.

| Round | Queue at start | `qLen` | Served | `level` | Queue at end |
|---|---|---|---|---|---|
| 1 | `[3]` | 1 | 3 | `[3]` | `[9, 20]` |
| 2 | `[9, 20]` | 2 | 9, 20 | `[9, 20]` | `[∅, ∅, 15, 7]` |
| 3 | `[∅, ∅, 15, 7]` | 4 | ∅, ∅, 15, 7 | `[15, 7]` | `[∅, ∅, ∅, ∅]` |
| 4 | `[∅, ∅, ∅, ∅]` | 4 | all ∅ | `[]` (not saved) | `[]` |

The queue is empty, so we stop: `[[3], [9, 20], [15, 7]]` ✅

## How fast is it?
- **Time: O(n).** Every node joins and leaves the queue once.
- **Space: O(n).** The queue can hold a whole level, up to about half the nodes.
