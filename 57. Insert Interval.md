# 57. Insert Interval
LeetCode: https://leetcode.com/problems/insert-interval/ · Medium · Pattern: Intervals (linear scan + merge)

## Problem
You're given non-overlapping intervals sorted by start, and a `newInterval`. Insert it, merging any overlaps, so the result is still sorted and non-overlapping.

**Example**
```
Input: intervals = [[1,3],[4,6]], newInterval = [2,5]
Output: [[1,6]]
```

## Solution
```python
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []

        for i in range(len(intervals)):
            if newInterval[1] < intervals[i][0]:
                res.append(newInterval)
                return res + intervals[i:]
            elif newInterval[0] > intervals[i][1]:
                res.append(intervals[i])
            else:
                newInterval = [min(newInterval[0], intervals[i][0]),
                               max(newInterval[1], intervals[i][1])]

        res.append(newInterval)
        return res
```

Using `intervals = [[1,3],[6,9]]`, `newInterval = [2,5]`:

1. For each existing interval there are exactly three cases relative to `newInterval`.
2. **New ends before it starts** (`new.end < cur.start`): no overlap, and everything after `cur` is even later. Add `newInterval`, then add the rest of the list untouched, and return.
3. **New starts after it ends** (`new.start > cur.end`): `cur` is entirely to the left. Add it to the result as is.
4. **Otherwise they overlap** → merge into one bigger interval: `[min(starts), max(ends)]`. Don't add it yet, because it might overlap the next interval too.
5. `[1,3]` vs `[2,5]`: `5 < 1`? No. `2 > 3`? No → overlap → `newInterval = [1,5]`.
6. `[6,9]` vs `[1,5]`: `5 < 6` → case 1. Add `[1,5]`, then `[6,9]` → `[[1,5],[6,9]]`.
7. If the loop finishes without hitting case 1, the new interval belongs at the end, so `res.append(newInterval)`.

One pass over already-sorted input: O(n) time, O(n) space for the output.
