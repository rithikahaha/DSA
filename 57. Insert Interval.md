# 57. Insert Interval
LeetCode: https://leetcode.com/problems/insert-interval/ · Medium · Pattern: Intervals (linear scan + merge)

## Problem
You have a list of **non-overlapping intervals, sorted by start**. Insert one new interval, **merging anything it overlaps**, so the list stays sorted and non-overlapping.

```
Input:  intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]],  newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
   ([4,8] overlaps [3,5], [6,7] and [8,10], so they all merge into [3,10])
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **interval `[a, b]`** | A stretch of numbers from `a` to `b`. |
| **overlap** | Two intervals share some numbers. |
| **merge** | Combine overlapping intervals into one big one: `[min of starts, max of ends]`. |
| **`res + intervals[i:]`** | The answer so far, followed by *all the remaining intervals from position `i` onward*. |

## How to come up with it (the thinking)
**Step 1: the intervals are sorted, so walk through them left to right.** For each existing interval, compare it with the new one. There are only **three possibilities**:

1. **The new interval is completely to the left** (it ends before this one starts). No overlap, and every later interval is even further right. So: add the new interval, then all the remaining intervals as they are. **Finished.**
2. **The new interval is completely to the right** (it starts after this one ends). No overlap. This existing interval belongs in the answer unchanged. Keep going.
3. **They overlap.** Merge them into one bigger interval and let *that* be the new interval (it may overlap the next ones too). Keep going.

**Step 2: after the loop.** If we never hit case 1, the new (possibly merged) interval belongs at the very end. Add it.

## Solution
```python
class Solution:
    def insert(self, intervals: List[List[int]], newInterval: List[int]) -> List[List[int]]:
        res = []

        for i in range(len(intervals)):
            if newInterval[1] < intervals[i][0]:
                res.append(newInterval)
                return res + intervals[i:]
            elif newInterval[0] > intervals[i][1]:
                res.append(intervals[i])
            else:
                newInterval = [min(newInterval[0], intervals[i][0]),
                               max(newInterval[1], intervals[i][1])]

        res.append(newInterval)
        return res
```

## Line by line
| Line | What it does |
|---|---|
| `res = []` | The answer we're building. |
| `for i in range(len(intervals)):` | Go through the existing intervals in order. |
| `if newInterval[1] < intervals[i][0]:` | Case 1: the new interval **ends before** this one **starts**. |
| `res.append(newInterval)` | Add the new interval. |
| `return res + intervals[i:]` | Then add this interval and everything after it, untouched. Done. |
| `elif newInterval[0] > intervals[i][1]:` | Case 2: the new interval **starts after** this one **ends**. |
| `res.append(intervals[i])` | This existing interval stays as is. |
| `else:` | Case 3: they overlap. |
| `newInterval = [min(starts), max(ends)]` | Merge: take the earliest start and the latest end. |
| `res.append(newInterval)` | After the loop, the new interval goes at the end. |

## Watch it run
`intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]]`, `newInterval = [4,8]`

| Existing `[a,b]` | `new` before | New ends (8) < `a`? | New starts (4) > `b`? | Case | `new` after | `res` |
|---|---|---|---|---|---|---|
| [1,2] | [4,8] | 8 < 1? No | 4 > 2? **Yes** | 2: add existing | [4,8] | `[[1,2]]` |
| [3,5] | [4,8] | 8 < 3? No | 4 > 5? No | 3: **merge** | [3,8] | `[[1,2]]` |
| [6,7] | [3,8] | 8 < 6? No | 3 > 7? No | 3: **merge** | [3,8] | `[[1,2]]` |
| [8,10] | [3,8] | 8 < 8? No | 3 > 10? No | 3: **merge** | [3,10] | `[[1,2]]` |
| [12,16] | [3,10] | 10 < 12? **Yes** | | 1: add new, then the rest | | `[[1,2],[3,10],[12,16]]` → **return** |

Answer: `[[1,2],[3,10],[12,16]]` ✅

## How fast is it?
- **Time: O(n).** One pass; the list was already sorted.
- **Space: O(n).** The answer list.
