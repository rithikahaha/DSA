# 11. Container With Most Water
LeetCode: https://leetcode.com/problems/container-with-most-water/ · Medium · Pattern: Two pointers

## Problem
Given an array `height` where `height[i]` is the height of a vertical bar at position `i`, pick two bars that, together with the x-axis, form a container holding the most water. Return that maximum amount.

**Example**
```
Input: height = [1,7,2,5,4,7,3,6]
Output: 36      (bars at index 1 and 7: width 6 × height min(7,6) = 36)
```

## Solution
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        res = 0
        l, r = 0, len(height) - 1

        while l < r:
            area = (r - l) * min(height[l], height[r])
            res = max(res, area)

            if height[l] < height[r]:
                l += 1
            else:
                r -= 1

        return res
```

Using `height = [1,7,2,5]`:

1. Water held = width × the **shorter** of the two bars (water spills over the shorter side).
2. Start with the widest container: `l = 0`, `r = 3`. Area = `3 × min(1,5) = 3`.
3. Which pointer should move? The shorter bar is the limit. Moving the taller one only shrinks the width without raising the limit, so it can't help. Move the shorter one: `l = 1`.
4. `l = 1`, `r = 3`: area = `2 × min(7,5) = 10`. Best so far is 10.
5. Now `height[l]=7 > height[r]=5`, so move `r` → `r = 2`: area = `1 × min(7,2) = 2`.
6. `l` and `r` meet, the loop stops → return `10`.

Checking every pair is O(n²). Each step here discards one bar for good, so it's a single pass: O(n) time, O(1) space.
