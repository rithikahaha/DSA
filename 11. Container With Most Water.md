# 11. Container With Most Water
LeetCode: https://leetcode.com/problems/container-with-most-water/ · Medium · Pattern: Two pointers

## Problem
`height` is a list of vertical bars; `height[i]` is the height of bar `i`. Pick **two bars** as the left and right walls of a container. Find the **most water** any pair can hold.

```
Input:  height = [1, 7, 2, 5, 4, 7, 3, 6]
Output: 36      (bars at index 1 and 7: 6 apart, shorter wall is 6 → 6 × 6 = 36)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **width** | How far apart the two bars are: `r - l` (the difference of their positions). |
| **water held** | `width × the shorter wall`. Water spills over the lower wall, so the shorter bar decides the height. |
| **two pointers** | Two markers, `l` on the left and `r` on the right, that move toward each other. |

## How to come up with it (the thinking)
**Step 1: the obvious idea.** Try every pair of bars and compute the water for each. With n bars that's about n × n pairs. Slow.

**Step 2: start with the widest container.** Put `l` on the first bar and `r` on the last. The width is as big as it can ever be.

**Step 3: how can we do better?** Any narrower container has less width, so to hold more it needs a **taller shorter-wall**. The shorter wall is the limiting one. So which pointer should move?
- Move the **taller** bar's pointer: the width shrinks, and the shorter wall stays the same or gets worse. It **can't** improve. 🚫
- Move the **shorter** bar's pointer: the width shrinks, but we *might* find a taller wall. It's the only chance to improve. ✅

**Step 4: repeat.** Always move the pointer at the shorter bar, remember the best area seen, and stop when the pointers meet.

## Solution
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        res = 0
        l, r = 0, len(height) - 1

        while l < r:
            area = (r - l) * min(height[l], height[r])
            res = max(res, area)

            if height[l] < height[r]:
                l += 1
            else:
                r -= 1

        return res
```

## Line by line
| Line | What it does |
|---|---|
| `res = 0` | Best water amount found so far. |
| `l, r = 0, len(height) - 1` | `l` at the first bar, `r` at the last bar. |
| `while l < r:` | Keep going while the pointers haven't met. |
| `area = (r - l) * min(height[l], height[r])` | Width times the shorter of the two bars. |
| `res = max(res, area)` | Keep the bigger of the old best and this area. |
| `if height[l] < height[r]: l += 1` | Left bar is shorter → move the left pointer right. |
| `else: r -= 1` | Otherwise the right bar is shorter (or equal) → move the right pointer left. |

## Watch it run
`height = [1, 7, 2, 5]`

| `l` | `r` | `height[l]` | `height[r]` | Width `r-l` | Area = width × shorter | `res` | Move |
|---|---|---|---|---|---|---|---|
| 0 | 3 | 1 | 5 | 3 | 3 × 1 = 3 | 3 | left is shorter → `l = 1` |
| 1 | 3 | 7 | 5 | 2 | 2 × 5 = 10 | 10 | right is shorter → `r = 2` |
| 1 | 2 | 7 | 2 | 1 | 1 × 2 = 2 | 10 | right is shorter → `r = 1` |

Now `l == r`, so the loop stops. Answer: **10** ✅

## How fast is it?
- **Time: O(n).** Every step moves one pointer inward, so at most n steps.
- **Space: O(1).** Just a few variables.
