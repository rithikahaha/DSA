# 70. Climbing Stairs
LeetCode: https://leetcode.com/problems/climbing-stairs/ · Easy · Pattern: Dynamic programming (Fibonacci)

## Problem
You're climbing a staircase with `n` steps. Each move you can climb 1 or 2 steps. Return the number of distinct ways to reach the top.

**Example 1**
```
Input: n = 2
Output: 2      (1+1, or 2)
```

**Example 2**
```
Input: n = 3
Output: 3      (1+1+1, 1+2, 2+1)
```

## Solution
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        one, two = 1, 1

        for i in range(n - 1):
            temp = one
            one = one + two
            two = temp

        return one
```

Using `n = 4`:

1. Look at the **last move**. To stand on step `n`, you came from step `n-1` (a 1-step move) or from step `n-2` (a 2-step move). So `ways(n) = ways(n-1) + ways(n-2)`. That's the Fibonacci sequence.
2. Only the previous two answers are ever needed, so two variables replace a whole table: `one = ways(n-1)`, `two = ways(n-2)`, both starting at 1.
3. Each loop turns `(one, two)` into `(one + two, old one)`. It runs `n - 1` times.
4. `n = 4`: `(1,1)` → `(2,1)` → `(3,2)` → `(5,3)`.
5. Return `one` → `5`.

The ways for n = 1, 2, 3, 4 are 1, 2, 3, 5. A recursive version recomputes the same sub-answers over and over (O(2ⁿ)). Remembering just the last two makes it O(n) time and O(1) space.
