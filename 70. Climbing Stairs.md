# 70. Climbing Stairs
LeetCode: https://leetcode.com/problems/climbing-stairs/ · Easy · Pattern: Dynamic programming (Fibonacci)

## Problem
You're climbing a staircase with `n` steps. Each move you can climb **1 or 2 steps**. In how many **different ways** can you reach the top?

```
n = 2  →  2 ways:  1+1,  2
n = 3  →  3 ways:  1+1+1,  1+2,  2+1
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **dynamic programming (DP)** | Solve a big problem by building on the answers to smaller versions of it, and **remember** those answers instead of recalculating them. |
| **Fibonacci sequence** | 1, 1, 2, 3, 5, 8, ...: each number is the sum of the previous two. |
| **`ways(n)`** | How many ways to reach step `n`. |

## How to come up with it (the thinking)
**Step 1: look at the LAST move.** To be standing on step `n`, your final move was either:
- a **1-step** move from step `n−1`, or
- a **2-step** move from step `n−2`.

Those are the only two ways to arrive. Every way of reaching `n−1` plus a final 1-step is a way to reach `n`, and likewise for `n−2` plus a 2-step. So:

> **ways(n) = ways(n−1) + ways(n−2)**

**Step 2: small cases.** `ways(1) = 1` (just one step). `ways(0) = 1` (standing at the bottom: one way to do nothing). Then `ways(2) = 1 + 1 = 2`, `ways(3) = 2 + 1 = 3`, `ways(4) = 3 + 2 = 5`.

**Step 3: we only need the last two answers.** Instead of a long table, keep just two variables and slide them forward.

## Solution
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        one, two = 1, 1

        for i in range(n - 1):
            temp = one
            one = one + two
            two = temp

        return one
```

## Line by line
| Line | What it does |
|---|---|
| `one, two = 1, 1` | `one` = ways to reach the current step; `two` = ways to reach the step before it. We begin at step 1: `one = ways(1) = 1`, `two = ways(0) = 1`. |
| `for i in range(n - 1):` | Move up one step at a time: `n − 1` moves takes us from step 1 to step `n`. |
| `temp = one` | Remember the current `one`, since we're about to overwrite it. |
| `one = one + two` | New count = ways(this step) + ways(previous step). |
| `two = temp` | The old `one` is now "the step before". |
| `return one` | The ways to reach step `n`. |

## Watch it run
`n = 4` → the loop runs `n − 1 = 3` times.

| Loop | `temp` | `one` after (`one + two`) | `two` after | Meaning |
|---|---|---|---|---|
| start | | 1 | 1 | `ways(1) = 1`, `ways(0) = 1` |
| 1 | 1 | 1 + 1 = **2** | 1 | `ways(2) = 2` |
| 2 | 2 | 2 + 1 = **3** | 2 | `ways(3) = 3` |
| 3 | 3 | 3 + 2 = **5** | 3 | `ways(4) = 5` |

Answer: **5** ✅

## How fast is it?
- **Time: O(n).** One short loop.
- **Space: O(1).** Two variables. (Calling the formula recursively without remembering answers would be far slower, about 2ⁿ steps, because it recalculates the same values many times.)
