# 347. Top K Frequent Elements
LeetCode: https://leetcode.com/problems/top-k-frequent-elements/ · Medium · Pattern: Hash map + bucket sort

## Problem
Given a list of numbers `nums` and a number `k`, return the **`k` numbers that appear most often**, in any order.

```
Input:  nums = [1, 2, 2, 3, 3, 3],  k = 2
Output: [2, 3]        (3 appears 3 times, 2 appears twice, 1 only once)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **frequency** | How many times something appears. |
| **dictionary** | A phone book from a key to a value. Here: number → how many times it appears. |
| **bucket** | A labelled box. We use a row of boxes numbered 0, 1, 2, ... where box number = "how many times". |
| **`range(a, b, -1)`** | Counts **down** from `a` to just above `b`. `range(6, 0, -1)` gives 6, 5, 4, 3, 2, 1. |

## How to come up with it (the thinking)
**Step 1: count.** First find out how often each number appears: `{1:1, 2:2, 3:3}`. A dictionary does this in one pass.

**Step 2: the obvious idea.** Sort the numbers by their count and take the top `k`. That works, but sorting is extra work.

**Step 3: the trick.** A count can never be bigger than the length of the list, so make a row of boxes numbered `0` up to `len(nums)`. Drop each number into the box matching its count. Now the numbers are **already sorted by frequency**, with no sorting needed.

**Step 4: collect the answer.** Start at the last box (highest frequency) and walk backwards, picking up numbers until we have `k` of them.

## Solution
```python
class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = {}
        freq = [[] for i in range(len(nums) + 1)]

        for n in nums:
            count[n] = 1 + count.get(n, 0)
        for n, c in count.items():
            freq[c].append(n)

        res = []
        for i in range(len(freq) - 1, 0, -1):
            for n in freq[i]:
                res.append(n)
                if len(res) == k:
                    return res
```

## Line by line
| Line | What it does |
|---|---|
| `count = {}` | Empty tally: number → times seen. |
| `freq = [[] for i in range(len(nums) + 1)]` | The row of boxes. Box `i` is an empty list. There are `len(nums) + 1` boxes because a count can be anything from 0 to `len(nums)`. |
| `for n in nums: count[n] = 1 + count.get(n, 0)` | Tally each number (add 1 to its old count, or start from 0). |
| `for n, c in count.items():` | Go through each number `n` and its count `c`. |
| `freq[c].append(n)` | Drop number `n` into the box numbered `c`. |
| `res = []` | The answer so far (empty). |
| `for i in range(len(freq) - 1, 0, -1):` | Walk the boxes from the **last** one down to box 1 (highest frequency first). |
| `for n in freq[i]:` | Look at every number in this box. |
| `res.append(n)` | Add it to the answer. |
| `if len(res) == k: return res` | Once we have `k` numbers, stop and return them. |

## Watch it run
`nums = [1, 2, 2, 3, 3, 3]`, `k = 2`

Counting: `count = {1: 1, 2: 2, 3: 3}`

Filling the boxes:

| Box (count) | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| Numbers inside | | 1 | 2 | 3 | | | |

Walking backwards from box 6:

| Box `i` | Numbers inside | `res` after | Have `k=2`? |
|---|---|---|---|
| 6, 5, 4 | (empty) | `[]` | No |
| 3 | 3 | `[3]` | No |
| 2 | 2 | `[3, 2]` | **Yes** → return `[3, 2]` |

## How fast is it?
- **Time: O(n).** Count once, fill boxes once, walk the boxes once. No sorting.
- **Space: O(n).** The tally and the boxes.
