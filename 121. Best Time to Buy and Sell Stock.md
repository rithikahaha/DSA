# 121. Best Time to Buy and Sell Stock
LeetCode: https://leetcode.com/problems/best-time-to-buy-and-sell-stock/ · Easy · Pattern: Two pointers / sliding window

## Problem
`prices[i]` is a stock's price on day `i`. Choose one day to buy and a **later** day to sell. Return the maximum profit, or `0` if no profit is possible.

**Example 1**
```
Input: prices = [10,1,5,6,7,1]
Output: 6      (buy at 1, sell at 7)
```

**Example 2**
```
Input: prices = [10,8,7,5,2]
Output: 0      (prices only fall)
```

## Solution
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        l, r = 0, 1
        maxP = 0
        while r < len(prices):
            if prices[l] < prices[r]:
                profit = prices[r] - prices[l]
                maxP = max(maxP, profit)
            else:
                l = r
            r += 1
        return maxP
```

Using `prices = [10,1,5,6,7,1]`:

1. `l` is the day we'd buy and `r` is the day we'd sell. `r` always stays ahead of `l`.
2. r=1 (price 1): `1 < 10` is false, so the sell price is lower than the buy price. That's a better day to buy → `l = 1`.
3. r=2 (5): profit `5 - 1 = 4` → `maxP = 4`.
4. r=3 (6): profit 5 → `maxP = 5`.
5. r=4 (7): profit 6 → `maxP = 6`.
6. r=5 (1): `1 < 1` is false → `l = 5`. End → `6`.

The idea is to always buy at the cheapest price seen so far and check what selling today would earn. The brute force checks every buy/sell pair, O(n²); this is one pass, O(n) time and O(1) space.
