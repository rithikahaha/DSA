# 141. Linked List Cycle
LeetCode: https://leetcode.com/problems/linked-list-cycle/ · Easy · Pattern: Slow / fast pointers

## Problem
Given the head of a linked list, return `True` if the list has a **cycle** (following `next` eventually leads back to a node you've already visited), else `False`.

```
1 → 2 → 3 → 4
    ↑       │
    └───────┘      (4 points back to 2)      Output: True
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **linked list** | A chain of people holding hands; each **node** knows who is next (`next`). A normal chain ends in `None` ("nobody"). |
| **cycle** | The last person holds hands with someone earlier, so the chain becomes a loop and never ends. |
| **slow / fast pointer** | Two markers walking the chain. `slow` takes 1 step at a time; `fast` takes 2. |

## How to come up with it (the thinking)
**Step 1: how could we tell?** If there's no cycle, walking forward eventually reaches `None`. If there's a cycle, you'd walk forever.

**Step 2: the obvious idea.** Write down every node you visit. If you land on one you've already written down, there's a cycle. It works, but takes extra memory for the notebook.

**Step 3: the trick, using a racetrack.** Two runners start together. One runs at normal speed, the other at double speed.
- On a **straight road** (no cycle), the fast runner just reaches the end first.
- On a **circular track** (cycle), the fast runner laps the slow one, so they **must meet**.

**Step 4: turn it into code.** Move `slow` one step and `fast` two steps. If they ever stand on the same node → cycle. If `fast` falls off the end (`None`) → no cycle.

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow, fast = head, head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                return True

        return False
```

## Line by line
| Line | What it does |
|---|---|
| `slow, fast = head, head` | Both runners start at the first node. |
| `while fast and fast.next:` | Keep going as long as the fast runner can take two steps (it hasn't hit the end). |
| `slow = slow.next` | Slow runner moves 1 step. |
| `fast = fast.next.next` | Fast runner moves 2 steps. |
| `if slow == fast:` | Are they standing on the same node? |
| `return True` | Yes → they met on a loop, so there's a cycle. |
| `return False` | `fast` reached the end (`None`) → the list ends, no cycle. |

## Watch it run
`1 → 2 → 3 → 4 → (back to 2)`

| Step | `slow` moves to | `fast` moves to | Same node? |
|---|---|---|---|
| start | 1 | 1 | |
| 1 | 2 | 3 | No |
| 2 | 3 | 2 (3 → 4 → 2) | No |
| 3 | 4 | 4 (2 → 3 → 4) | **Yes** → return `True` |

(With no cycle, e.g. `1 → 2 → 3`: `fast` goes 1 → 3 → then `fast.next` is `None`, so the loop ends → `False`.)

## How fast is it?
- **Time: O(n).** The runners meet within about n steps.
- **Space: O(1).** Just two markers, no notebook.
