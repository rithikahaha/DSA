# 141. Linked List Cycle
LeetCode: https://leetcode.com/problems/linked-list-cycle/ · Easy · Pattern: Slow / fast pointers

## Problem
Given the head of a linked list, return `true` if the list contains a cycle (some node's `next` points back to an earlier node), otherwise `false`.

**Example**
```
Input: head = [1,2,3,4], with the tail (4) pointing back to index 1 (node 2)
Output: true
```

## Solution
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow, fast = head, head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            if slow == fast:
                return True

        return False
```

Using `1 → 2 → 3 → 4 → (back to 2)`:

1. `slow` moves one node per step and `fast` moves two. Think of two runners on a track.
2. **No cycle:** `fast` reaches the end (`None`) first. The loop condition `fast and fast.next` stops there → `False`.
3. **Cycle:** both runners end up on the loop, and the faster one gains one node on the slower one each step, so it must eventually land on the same node.
4. Trace: slow=1, fast=1 → slow=2, fast=3 → slow=3, fast=2 (3 → 4 → 2) → slow=4, fast=4 → `slow == fast` → `True`.

Storing visited nodes in a set also works but costs O(n) memory. Two pointers give O(n) time and O(1) space.
