# 198. House Robber
LeetCode: https://leetcode.com/problems/house-robber/ · Medium · Pattern: Dynamic programming

## Problem
`nums[i]` is the money in house `i`. You can't rob two adjacent houses. Return the maximum amount you can rob.

**Example 1**
```
Input: nums = [1,1,3,3]
Output: 4      (rob house 0 and house 2 or 3: 1 + 3)
```

**Example 2**
```
Input: nums = [2,9,8,3,6]
Output: 16     (2 + 8 + 6)
```

## Solution
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        rob1, rob2 = 0, 0

        for n in nums:
            temp = max(n + rob1, rob2)
            rob1 = rob2
            rob2 = temp
        return rob2
```

Using `nums = [2,9,8,3,6]`:

1. At each house you make one decision: **rob it** or **skip it**.
   - Rob it → you get `n` plus the best from the houses up to **two back** (`rob1`), because the previous house is off-limits.
   - Skip it → you keep the best so far from the previous house (`rob2`).
2. `rob2` is the best total up to the previous house. `rob1` is the best total up to the house before that. Both start at 0.
3. New best = `max(n + rob1, rob2)`. Then shift the window: `rob1 = rob2`, `rob2 = new best`.
4. Walk through it:

   | house | n | `n + rob1` | `rob2` | new best |
   |---|---|---|---|---|
   | 0 | 2 | 2 | 0 | 2 |
   | 1 | 9 | 9 | 2 | 9 |
   | 2 | 8 | 10 | 9 | 10 |
   | 3 | 3 | 12 | 10 | 12 |
   | 4 | 6 | 16 | 12 | **16** |

5. The last `rob2` is the answer → `16`.

The same idea written with a table is `dp[i] = max(dp[i-1], nums[i] + dp[i-2])`. Since only the last two entries are used, two variables are enough: O(n) time, O(1) space.
