# 190. Reverse Bits
LeetCode: https://leetcode.com/problems/reverse-bits/ · Easy · Pattern: Bit manipulation

## Problem
Given a 32-bit unsigned integer `n`, reverse its bits and return the result.

**Example**
```
Input: n = 00000000000000000000000000010101   (21)
Output: 10101000000000000000000000000000      (2818572288)
```

## Solution
```python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0

        for i in range(32):
            bit = (n >> i) & 1
            res = res | (bit << (31 - i))
        return res
```

Using an 8-bit analogy, `n = 00010101` (positions counted from the right, 0 to 7):

1. Reversing means the bit at position `i` moves to position `31 - i`. (With 8 bits it would be `7 - i`.)
2. `(n >> i) & 1` reads the bit at position `i`. Shifting right by `i` brings that bit to the last position, and `& 1` masks off everything else.
3. `bit << (31 - i)` places that bit at its mirrored position.
4. `res | ...` (bitwise OR) writes the bit into `res` without disturbing the bits already placed.
5. Repeat for all 32 positions. In the 8-bit version: the `1` at position 0 goes to 7, the `1` at position 2 goes to 5, and the `1` at position 4 goes to 3, giving `10101000`.

There are always exactly 32 iterations: O(1) time and space.
