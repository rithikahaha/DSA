# 20. Valid Parentheses
LeetCode: https://leetcode.com/problems/valid-parentheses/ · Easy · Pattern: Stack

## Problem
Given a string `s` containing only `()[]{}`, return `true` if every open bracket is closed by the same type of bracket, in the correct order.

**Example 1**
```
Input: s = "[]"
Output: true
```

**Example 2**
```
Input: s = "([{}])"     → true
Input: s = "[(])"       → false
```

## Solution
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        closeToOpen = {")": "(", "]": "[", "}": "{"}
        for c in s:
            if c in closeToOpen:
                if stack and stack[-1] == closeToOpen[c]:
                    stack.pop()
                else:
                    return False
            else:
                stack.append(c)
        return True if not stack else False
```

Using `s = "[(])"`:

1. The most recently opened bracket must be the first one closed. That's last-in, first-out, which is a stack.
2. `closeToOpen` maps each closing bracket to the opener it needs.
3. `[` is an opener → push. `(` is an opener → push. Stack: `[ (`.
4. `]` is a closer that needs `[`, but the top of the stack is `(` → mismatch → return `False`.
5. For a valid string like `"([{}])"` every closer finds its match on top and pops. At the end the stack is empty → `True`. A leftover opener (like `"(("`) means the stack isn't empty → `False`.

One pass: O(n) time, O(n) space.
