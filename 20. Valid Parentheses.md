# 20. Valid Parentheses
LeetCode: https://leetcode.com/problems/valid-parentheses/ · Easy · Pattern: Stack

## Problem
A string contains only these characters: `( ) [ ] { }`. Return `True` if every opening bracket is closed by the **same type** of bracket, **in the right order**.

```
"[]"      → True
"([{}])"  → True
"[(])"    → False      (the ( is still open when the ] tries to close the [)
```

## Words you need first
| Word | Plain-English meaning |
|---|---|
| **stack** | A pile of plates. You can only add a plate on **top** and remove the plate from the **top**. The last plate you put on is the first one you take off ("last in, first out"). |
| **push** | Put something on top of the pile. In Python: `stack.append(x)`. |
| **pop** | Take the top thing off. In Python: `stack.pop()`. |
| **`stack[-1]`** | Peek at the top item without removing it. |

## How to come up with it (the thinking)
**Step 1: notice the rule.** Brackets nest like boxes inside boxes. The **most recently opened** bracket must be the **first one closed**. For `([])`: open `(`, open `[`, then the `[` must close before the `(` does.

**Step 2: "last opened, first closed" is exactly a stack.** Each time we see an opening bracket, put it on the pile. When we see a closing bracket, it must match the plate on **top**. If it does, remove that plate. If not (or the pile is empty), the string is invalid.

**Step 3: the ending check.** After reading everything, the pile should be empty. If plates remain, some brackets were never closed.

## Solution
```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        closeToOpen = {")": "(", "]": "[", "}": "{"}
        for c in s:
            if c in closeToOpen:
                if stack and stack[-1] == closeToOpen[c]:
                    stack.pop()
                else:
                    return False
            else:
                stack.append(c)
        return True if not stack else False
```

## Line by line
| Line | What it does |
|---|---|
| `stack = []` | An empty pile. |
| `closeToOpen = {")": "(", ...}` | A phone book: for each **closing** bracket, which **opening** bracket it needs. |
| `for c in s:` | Read the string one character at a time. |
| `if c in closeToOpen:` | Is this character a closing bracket? |
| `if stack and stack[-1] == closeToOpen[c]:` | Is the pile non-empty **and** is the top plate the matching opener? |
| `stack.pop()` | Yes → the pair matches, remove the opener. |
| `else: return False` | No match (wrong type, or nothing to close) → invalid. |
| `else: stack.append(c)` | It's an opening bracket → put it on the pile. |
| `return True if not stack else False` | At the end, an empty pile means everything was closed → `True`. |

## Watch it run
`s = "[(])"`

| Step | `c` | Type | Top of stack | Match? | Stack after |
|---|---|---|---|---|---|
| 1 | `[` | opener | | | `[` |
| 2 | `(` | opener | | | `[ (` |
| 3 | `]` | closer, needs `[` | `(` | **No** (top is `(`) | return `False` |

Now a valid one, `s = "([])"`:

| Step | `c` | Top of stack | What happens | Stack after |
|---|---|---|---|---|
| 1 | `(` | | push | `(` |
| 2 | `[` | | push | `( [` |
| 3 | `]` | `[` | matches → pop | `(` |
| 4 | `)` | `(` | matches → pop | *(empty)* |

The pile is empty at the end → `True` ✅

## How fast is it?
- **Time: O(n).** One pass; push and pop are instant.
- **Space: O(n).** The pile can hold up to n openers.
